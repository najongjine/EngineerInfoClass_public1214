# 정보처리기사 학습 대시보드

흩어져 있던 **1–20번 이론 모의고사·코딩 교재 40개와 SQL 교재 3개**를 한 화면에서 볼 수 있습니다. 번호는 학습 순서이며, 정해진 날짜나 기간에 맞춰 끝낼 필요가 없습니다.

## 사용하기

[웹 대시보드 열기](https://engineer-info-class-hub.blackarbor4.chatgpt.site) — 현재 본인 전용으로 배포되어 있습니다.

이 저장소를 다운로드한 뒤 **`index.html`을 브라우저로 열면** 바로 사용할 수 있습니다. 교재 제목을 클릭하면 실제 HTML 교재가 새 탭에서 열립니다.

- 번호순 이론 모의고사·코딩 교재 목록과 SQL 보충 교재
- 번호 범위별 바로가기
- 교재 제목, 번호, 언어 검색
- 모바일 화면 및 인쇄 지원

교재를 찾고 바로 열 수 있도록 검색과 목록만 제공합니다.

## 교재를 추가하거나 수정한 경우

`교재/` 폴더의 HTML 파일을 수정한 뒤 Node.js로 다음 명령을 실행하세요.

```sh
node scripts/build-dashboard.mjs
```

파일의 제목과 번호를 읽어 `dashboard-data.js`를 갱신하고, 웹 호스팅용 파일을 `dashboard-site/dist/`에 준비합니다. 교재 원본은 수정하지 않습니다. 목록은 읽기 편하도록 번호 5개씩 묶습니다. 기존 링크와 답안 저장 정보의 호환성을 위해 교재 파일명은 유지합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 대시보드 시작 페이지 |
| `dashboard.css` | 반응형 화면 디자인 |
| `dashboard.js` | 번호순 교재 목록과 검색 |
| `dashboard-data.js` | 교재에서 자동 생성한 목록 |
| `scripts/build-dashboard.mjs` | 목록 갱신 및 배포용 파일 준비 |
| `교재/` | 기존 교재 원본 |

외부 글꼴이나 라이브러리 없이 시스템 글꼴을 사용하며, 대시보드와 교재는 로컬에서 열 수 있습니다.
