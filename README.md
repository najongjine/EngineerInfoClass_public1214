# 정보처리기사 학습 대시보드

흩어져 있던 **20일 과정의 이론·코딩 교재 40개와 SQL 교재 3개**를 한 화면에서 볼 수 있습니다.

## 사용하기

[웹 대시보드 열기](https://engineer-info-class-hub.blackarbor4.chatgpt.site) — 현재 본인 전용으로 배포되어 있습니다.

이 저장소를 다운로드한 뒤 **`index.html`을 브라우저로 열면** 바로 사용할 수 있습니다. 교재 제목을 클릭하면 실제 HTML 교재가 새 탭에서 열립니다.

- 1–4주차 / 이론 / 코딩 / SQL 필터
- 교재 제목, 일차, 주제, 언어 검색 (검색 단축키 `/`)
- 즐겨찾기, 학습 완료 체크, 미완료 교재 필터
- 최근 교재 이어보기
- 모바일 화면 지원

즐겨찾기와 학습 기록은 **사용 중인 브라우저의 로컬 저장소**에 저장됩니다. 다른 기기나 브라우저와 동기화되지 않으며, 교재 내부의 답안·채점 기록과는 별개입니다.

## 교재를 추가하거나 수정한 경우

`교재/` 폴더의 HTML 파일을 수정한 뒤 Node.js로 다음 명령을 실행하세요.

```sh
node scripts/build-dashboard.mjs
```

파일의 제목과 일차를 읽어 `dashboard-data.js`를 갱신하고, 웹 호스팅용 파일을 `dashboard-site/dist/`에 준비합니다. 교재 원본은 수정하지 않습니다. 주차는 5일 단위로 묶습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 대시보드 시작 페이지 |
| `dashboard.css` | 반응형 화면 디자인 |
| `dashboard.js` | 검색, 필터, 즐겨찾기, 학습 기록 |
| `dashboard-data.js` | 교재에서 자동 생성한 목록 |
| `scripts/build-dashboard.mjs` | 목록 갱신 및 배포용 파일 준비 |
| `교재/` | 기존 교재 원본 |

외부 글꼴을 불러올 수 없어도 시스템 글꼴로 표시되며, 대시보드와 교재는 로컬에서 열 수 있습니다.
