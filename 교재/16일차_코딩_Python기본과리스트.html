3. 심화 설명 · 이름 두 개가 같은 리스트를 볼 수 있다

b=a는 리스트 복사가 아닙니다. 두 이름이 같은 리스트를 가리킵니다. a.copy() 또는 전체 슬라이스 a[:]는 바깥 리스트를 새로 만듭니다. 자세한 슬라이싱은17번에 배웁니다. 오늘은 copy를 먼저 사용하세요.

공유하는 대입과 복사 비교

a = [3, 6]
b = a
c = a.copy()
b[0] = 8
c.append(9)
print(a)
print(b)
print(c)
[8, 6]
[8, 6]
[3, 6, 9]

a와 b는 같은 리스트입니다. c는 바깥 리스트가 별개여서 c의 추가는 a·b에 영향을 주지 않습니다.

a ─┐ ├→ [8, 6] b ─┘ c ───→ [3, 6, 9] ← 별도 바깥 리스트
“얕은” 복사 · 안쪽에 또 리스트가 들어 있으면 그 안쪽 리스트는 공유될 수 있습니다. C34·C35는 선택 심화입니다. 1차원 정수 리스트의 칸 수정과 안쪽 객체 수정은 구별해서 읽습니다.

선택 심화 · 바깥만 복사한 경우

a = [[1, 3], [5, 7]]
b = a.copy()
b[0][0] = 9
b.append([0, 0])
print(a)
print(b)
[[9, 3], [5, 7]]
[[9, 3], [5, 7], [0, 0]]

안쪽[1,3]은 공유해9변경이 양쪽에 보입니다. b 바깥에 새 칸을 추가한 것은 a의 길이에 영향을 주지 않습니다.

제작 P01

설계 순서 · 빈 리스트 검사 → 합계와 인원을0에서 시작 → 원소마다 누적 → 마지막 평균 계산.
