1. 쉬운 설명 · 문자열을 칸으로 읽기

문자열은 글자가 순서대로 들어 있는 줄입니다. 첫 칸은 0번입니다. 음수 인덱스는 뒤에서 셉니다. 마지막 칸은 −1번입니다.

칸 번호012345
문자CODING
뒤에서 센 번호−6−5−4−3−2−1

E01 · 인덱스와 슬라이싱

s = "CODING"
print(s[0], s[-1])
print(s[1:4])
print(s[:3], s[3:])
실행 결과
C G
ODI
COD ING

s[1:4]는 1·2·3번을 가져옵니다. 끝 번호 4는 빼고 읽습니다. [:3]은 처음부터, [3:]은 끝까지입니다.

문법읽는 방법CODING에서 결과
s[1:5:2]1에서 시작, 5 직전, 2칸씩OI
s[::2]처음부터 2칸씩CDN
s[::-1]끝에서 앞으로 1칸씩GNIDOC
s[4:1:-1]4·3·2번 선택, 1은 제외NID
s[1:4:-1]뒤로 가는데 끝이 앞쪽에 없음빈 문자열

E02 · 음수 간격은 직접 칸 번호를 적기

s = "CODING"
print(s[-2:0:-2])
print(repr(s[1:4:-1]))
print(s[:99])
실행 결과
ND
''
CODING

첫 줄은 −2번=4번에서 시작해 4·2번을 읽으므로 ND입니다. repr은 빈 문자열도 ''로 보이게 해 줍니다. 인덱스 s[99]는 오류지만, 슬라이스의 큰 경계는 가능한 범위로 줄여집니다. 간격 0은 ValueError입니다.

음수 슬라이스의 마지막 함정 · s[::-1]은 첫 글자까지 뒤집습니다. s[:-1:-1]은 끝 경계 −1이 마지막 칸을 뜻하므로 빈 문자열입니다. 음수 간격에서 생략한 끝 경계와 직접 적은 −1은 다릅니다. 문자열 슬라이스는 새 문자열 값을 만듭니다. 리스트 슬라이스는 새 리스트를 만들지만 안쪽 객체까지 깊게 복사하지는 않습니다.

E03 · 문자열은 한 칸씩 수정하지 못함

s = "desk"
t = "t" + s[1:]
print(s, t)
s.replace("d", "r")
print(s)
s = s.replace("d", "r")
print(s)
실행 결과

s[0] = "t"는 TypeError입니다. 문자열을 바꾸려면 새 문자열을 만들고 이름에 다시 대입합니다. replace를 호출하기만 하면 원래 s는 그대로입니다.

split → 처리 → join

split은 문자열을 나누어 리스트로 만듭니다. join은 문자열들 사이에 구분자를 넣어 하나로 합칩니다. replace는 바꾼 새 문자열을 반환합니다. strip()은 양끝 공백만 지웁니다.

E04 · 나누고 합치기

raw = "  pen,book,bag  "
parts = raw.strip().split(",")
print(parts)
print(" / ".join(parts))

E08 · 중복 제거와 집합 연산

a = {"민", "준", "민", "서"}

a.add("준")

실행 결과

add로 같은 값을 다시 넣어도 개수는 늘지 않습니다. &는 공통, |는 모두, −는 왼쪽에만 있는 값입니다. sorted(set)은 정렬된 리스트를 돌려줍니다.

{}는 빈 dict입니다. 빈 set은 set()입니다. set에는 칸 번호가 없어 s[0]을 쓸 수 없습니다. remove(x)는 없는 값을 지우면 KeyError, discard(x)는 없어도 그대로 진행합니다. set에 넣는 값과 dict의 키는 해시 가능해야 합니다. 오늘은 숫자·문자열을 쓰면 됩니다. 리스트를 키로 쓰거나 set 원소로 넣으면 오류입니다.

E09 · 딕셔너리는 이름표로 찾기

scores = {"가람": 70, "보람": 85}
scores["가람"] = 88
scores["초롱"] = 79
print(scores["가람"])
print(scores.get("다솜", 0))
for name, point in scores.items():
    print(name, point)
실행 결과
88
0
가람 88
보람 85
초롱 79

이미 있는 키에 대입하면 값이 바뀝니다. 새 키에 대입하면 뒤에 추가됩니다. items는 키·값을 함께 꺼냅니다. 없는 키의 [] 접근은 KeyError이지만 get은 기본값을 줄 수 있습니다. get으로 읽는 것만으로 새 키가 생기지는 않습니다.

E10 · 딕셔너리로 개수 세기

words = "red blue red green blue red".split()
count = {}
for word in words:
    count[word] = count.get(word, 0) + 1
for word, n in count.items():
    print(word, n)
실행 결과
red 3
blue 2
green 1

처음 나온 단어는 get의 기본값 0에서 시작합니다. 같은 단어를 만날 때마다 1씩 더합니다. red → blue → red까지의 상태는 {red:1} → {red:1, blue:1} → {red:2, blue:1}입니다.

3. 심화 설명 · 반복을 줄여 쓰고 함정 구별하기

리스트 컴프리헨션은 새 리스트를 만드는 반복문입니다. 먼저 일반 for문으로 읽은 뒤 짧게 줄입니다. [변환식 for 원소 in 자료 if 조건]은 “자료에서 하나 꺼내고 → 조건을 확인하고 → 변환한 값을 모은다”입니다.

E11 · 반복문과 컴프리헨션 비교

nums = [3, 8, 11, 14]
a = []
for n in nums:
    if n % 2 == 0:
        a.append(n + 1)
b = [n + 1 for n in nums if n % 2 == 0]
c = ["짝" if n % 2 == 0 else "홀" for n in nums]
print(a, b)
print(c)
실행 결과
[9, 15] [9, 15]
['홀', '짝', '홀', '짝']

뒤쪽 if는 원소를 걸러 개수를 줄입니다. 앞쪽 값 if 조건 else 다른값은 각 원소를 무엇으로 바꿀지 정해 원소 개수를 유지합니다. 오늘은 한 겹 컴프리헨션부터 익힙니다.

P04 · 상품 수량 합산기

품목:수량을 |로 구분한 입력을 읽어 품목별 수량을 합산하세요. 수량은 0 이상의 정수이며 빈 행은 건너뜁니다. 품목·수량 양끝 공백을 허용합니다. 품목:합계를 첫 등장 순서로 출력하세요.

시작 데이터
raw = "펜:2| 공책 :3|펜:5||지우개:0"
목표 출력
펜:7
공책:3
지우개:0
변경해서 검증할 입력기대 결과
raw = ""
출력 없음
raw = "펜:0|펜:0"
펜:0
정답과 풀이 열기완성 코드 예시
raw = "펜:2| 공책 :3|펜:5||지우개:0"
qty = {}
for row in raw.split("|"):
    if row.strip():
        name, amount = row.split(":")
        name = name.strip()
        qty[name] = qty.get(name, 0) + int(amount.strip())
for name, amount in qty.items():
    print(name + ":" + str(amount))

없는 품목은 0에서 시작합니다. 값 0도 유효하므로 출력에서 빼지 않습니다.

P05 · 연속 구간 탐색기

P06 · 필수 서류 확인기

required는 필수 서류명 목록, submitted는 쉼표 문자열입니다. 제출 서류의 공백·빈 항목·중복을 처리하고, 빠진 필수 서류를 정렬해 출력하세요. 모두 있으면 완료를 출력합니다. 추가 서류는 무시합니다.

시작 데이터
required = ["신청서", "사진", "서명"]
submitted = " 사진,신청서,사진, "
목표 출력
누락:서명
변경해서 검증할 입력기대 결과
submitted = "서명,사진,신청서,추가"
완료
required = []; submitted = ""
완료
정답과 풀이 열기완성 코드 예시
required = ["신청서", "사진", "서명"]
submitted = " 사진,신청서,사진, "
received = set([x.strip() for x in submitted.split(",") if x.strip()])
missing = sorted(set(required) - received)
if missing:
    print("누락:" + ",".join(missing))
else:
    print("완료")

필수−제출이 누락입니다. 제출−필수로 바꾸면 추가 서류를 구하게 됩니다.

P07 · 반별 합격 요약기

(반,이름,점수) 튜플 목록에서 기준점 이상만 반별로 묶으세요. 반과 이름은 첫 등장 순서로 유지하고 반:이름/이름 형태로 출력합니다. 합격자가 없는 반은 출력하지 않습니다.

시작 데이터
cut = 80
rows = [("1반", "가", 79), ("2반", "나", 90), ("1반", "다", 80), ("2반", "라", 83)]
목표 출력
1반:다
2반:나/라
변경해서 검증할 입력기대 결과
rows = []
출력 없음
rows = [("1반", "가", 80)]
1반:가
rows = [("1반", "가", 79)]
출력 없음
정답과 풀이 열기완성 코드 예시
cut = 80
rows = [("1반", "가", 79), ("2반", "나", 90), ("1반", "다", 80), ("2반", "라", 83)]
groups = {}
for room, name, score in rows:
    if room not in groups:
        groups[room] = []
    if score >= cut:
        groups[room].append(name)
for room, names in groups.items():
    if names:
        print(room + ":" + "/".join(names))

반은 합격 여부와 관계없이 처음 보았을 때 등록해야 전체 명단 기준 반 순서를 지킵니다. 이름은 합격한 순서로 추가합니다.

P08 · 코드 검사와 마스킹

코드는 대문자 영문 2개, -, 숫자 4개의 형식입니다. 유효한 코드만 남기고 중복을 첫 등장 순서로 제거하세요. 마지막 두 숫자는 **로 가리고 쉼표로 합칩니다. 유효한 코드가 없으면 빈 줄을 출력합니다.

시작 데이터
codes = ["AB-1234", "A-1234", "AB-1234", "CD-5678", "ef-1111", "ZZ-12x4"]
목표 출력
AB-12**,CD-56**
변경해서 검증할 입력기대 결과
codes = []
빈 줄 1개
codes = ["AB-1234", "AB-1299"]
AB-12**,AB-12**
codes = ["", "aB-1234", "AA-123"]
빈 줄 1개
정답과 풀이 열기완성 코드 예시
codes = ["AB-1234", "A-1234", "AB-1234", "CD-5678", "ef-1111", "ZZ-12x4"]
seen = set()
result = []
for item in codes:
    valid = len(item) == 7
    if valid:
        valid = item[2] == "-"
    if valid:
        valid = all(["A" <= ch <= "Z" for ch in item[:2]])
    if valid:
        valid = all(["0" <= ch <= "9" for ch in item[3:]])
    if valid and item not in seen:
        seen.add(item)
        result.append(item[:5] + "**")
print(",".join(result))

all은 안의 조건이 모두 참인지 확인합니다. 길이를 먼저 확인해야 item[2] 접근 오류를 피합니다. 중복 판정은 마스킹 전 원래 코드로 합니다.
