1. 쉬운 설명 · 객체마다 가진 값과 모두가 공유하는 값

학생마다 점수는 다르지만 전체 학생 수는 하나입니다. score는 객체 필드, count는 static 필드입니다. static은 클래스 이름으로 접근하면 무엇을 공유하는지 보입니다.

class Student {
    String name;
    int score;
    static int count;
    Student(String name,int score){
        this.name=name;this.score=score;count++;
    }
}
public class Main {
    public static void main(String[] args){
        Student a=new Student("가",70);
        Student b=new Student("나",90);
        a.score+=5;
        System.out.println(a.score+" "+b.score);
        System.out.println(Student.count);
    }
}

class Calculator {

public class Main {

2. 응용 설명 · final과 접근 범위

final 변수는 한 번 값을 정하면 다시 대입할 수 없습니다. private 필드는 클래스 밖에서 직접 바꾸지 못하도록 하고, 필요한 동작만 메서드로 공개합니다. public은 어디서든 접근 가능하고, 아무 표시가 없으면 같은 패키지에서만 접근할 수 있습니다. protected는 같은 패키지와 다른 패키지의 자식 클래스에서 접근할 수 있습니다.

class Wallet {
    private int money;
    static final int LIMIT=1000;
    Wallet(int money){this.money=money;}
    boolean spend(int amount){
        if(amount<0 || amount>LIMIT || amount>money)return false;
        money-=amount;return true;
    }
    int balance(){return money;}
}
public class Main {
    public static void main(String[] args){
        Wallet w=new Wallet(1200);
        System.out.println(w.spend(500));
        System.out.println(w.balance());
        System.out.println(w.spend(1500));
    }
}
true
700
false

LIMIT는 모든 Wallet 객체가 공유하는 상수입니다. final 참조 변수라면 다른 객체로 재대입할 수 없지만, 그 객체의 변경 가능한 필드까지 모두 잠그는 뜻은 아닙니다.

3. 심화 설명 · 추상 클래스와 인터페이스

추상 클래스는 “이 기능은 반드시 있어야 하지만 구체 동작은 자식이 정해”라는 설계도입니다. 추상 메서드에는 본문이 없습니다. 추상 클래스를 직접 new할 수 없고, 구체 자식이 필요한 메서드를 구현합니다.

abstract class Shape {
    String name;
    Shape(String name){this.name=name;}
    abstract int area();
    void show(){System.out.println(name+":"+area());}
}
class Rectangle extends Shape {
    int width,height;
    Rectangle(int width,int height){
        super("직사각형");this.width=width;this.height=height;
    }
    @Override int area(){return width*height;}
}
public class Main {
    public static void main(String[] args){
        Shape s=new Rectangle(3,4);
        s.show();
    }
}
직사각형:12

인터페이스는 “이 메서드를 제공해야 한다”는 약속입니다. 클래스는 한 클래스만 extends할 수 있지만 여러 인터페이스를 implements할 수 있습니다. 인터페이스 타입 변수는 구현 객체를 가리킬 수 있습니다.

interface Printable { String print(); }
interface Savable { String save(); }
class Report implements Printable,Savable {
    public String print(){return "출력";}
    public String save(){return "저장";}
}
public class Main {
    public static void main(String[] args){
        Report r=new Report();
        Printable p=r;
        Savable s=r;
        System.out.println(p.print()+" "+s.save());
    }
}
출력 저장

인터페이스의 추상 메서드는 public이므로 구현 메서드도 public이어야 합니다. 변수 타입이 Printable이면 print()는 보이지만 save()는 보이지 않습니다. 실제 Report 객체가 두 약속을 모두 구현했더라도 참조 변수의 타입이 호출 가능한 메서드를 먼저 제한합니다.

제작 P02

재고 상한선

창고의 최대 보관 수량을 static final로 정하고, private 재고가 상한을 넘지 않도록 add를 구현하세요.

예시 구현과 확인
class Stock {
    static final int MAX=10;
    private int count;
    boolean add(int amount){
        if(amount<=0||count+amount>MAX)return false;
        count+=amount;return true;

public class Main {
    public static void main(String[] args){
        Stock s=new Stock();
        System.out.println(s.add(7));
        System.out.println(s.add(5));
        System.out.println(s.current());
    }
}

제작 P03

도형 넓이 계산

Shape를 추상 클래스로 만들고 Rectangle과 Square가 area()를 구현하게 하세요. 부모 타입 배열에서 모든 넓이를 합산하세요.

예시 구현과 확인
abstract class Shape { abstract int area(); }
class Rectangle extends Shape {
    int w,h;
    Rectangle(int w,int h){this.w=w;this.h=h;}
    @Override int area(){return w*h;}
}
class Square extends Shape {
    int side;
    Square(int side){this.side=side;}
    @Override int area(){return side*side;}
}
public class Main {
    public static void main(String[] args){
        Shape[] shapes={new Rectangle(3,4),new Square(5)};
        int sum=0;for(Shape s:shapes)sum+=s.area();
        System.out.println(sum);
    }
}

37이 출력됩니다. 추상 타입 배열이 서로 다른 구체 객체를 담습니다.

제작 P06

급여 계산

Employee 추상 클래스에 이름과 추상 pay()를 넣으세요. 월급제와 시급제 자식을 만들고 전체 급여를 합산하세요.

예시 구현과 확인
abstract class Employee {
    String name;
    Employee(String name){this.name=name;}
    abstract int pay();
}
class Monthly extends Employee {
    int salary;
    Monthly(String name,int salary){super(name);this.salary=salary;}
    @Override int pay(){return salary;}
}
class Hourly extends Employee {
    int hours,rate;
    Hourly(String name,int hours,int rate){super(name);this.hours=hours;this.rate=rate;}
    @Override int pay(){return hours*rate;}
}
public class Main {
    public static void main(String[] args){
        Employee[] e={new Monthly("가",100),new Hourly("나",3,20)};
        int sum=0;for(Employee x:e)sum+=x.pay();
        System.out.println(sum);
    }
}

예시 구현과 확인
abstract class Sensor {
    String name;
    Sensor(String name){this.name=name;}
    abstract boolean danger();
    void show(){System.out.println(name+":"+danger());}
}
class TemperatureSensor extends Sensor {
    int degree;
    TemperatureSensor(int degree){super("온도");this.degree=degree;}
    @Override boolean danger(){return degree>=40;}
}
class SmokeSensor extends Sensor {

    @Override boolean danger(){return detected;}
}
public class Main {
    public static void main(String[] args){
        Sensor[] s={new TemperatureSensor(42),new SmokeSensor(false)};
        for(Sensor x:s)x.show();
    }
}
