E01 · 틀 하나로 학생 두 명 만들기

class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

a = Student("민지", 70)
b = Student("준호", 85)
print(a.name, a.score)
print(b.name, b.score)
실행 결과
민지 70
준호 85

Student("민지", 70)를 실행하면 새 객체가 만들어지고 __init__이 이름과 점수를 넣습니다. a와 b는 서로 다른 학생 객체를 가리킵니다. 클래스 안쪽은 네 칸, 메서드 안쪽은 여덟 칸 들여 씁니다.

E02 · self는 지금 호출한 객체

class Account:
    def __init__(self, balance):
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount

a = Account(1000)
b = Account(3000)
a.deposit(500)
print(a.balance, b.balance)
실행 결과
1500 3000

a.deposit(500)의 self는 a가 가리키는 계좌입니다. 호출할 때 self 자리에 a를 따로 쓰지 않습니다. a의 잔액만 1500이 되고 b의 잔액은 그대로입니다.

E03 · 메서드도 매개변수와 return을 사용

class Item:

E05 · 같은 이름의 인스턴스 변수가 생기는 순간

class Ticket:
    price = 1000

a = Ticket()
b = Ticket()
a.price += 200
Ticket.price = 1500
print(a.price, b.price, Ticket.price)

처음 a.price는 클래스의 1000을 읽습니다. a.price += 200은 읽은 값으로 1200을 계산하고 a 자신의 price를 만듭니다. 이제 클래스 가격을 1500으로 바꿔도 a의 1200은 그대로입니다. b는 자기 price가 없으므로 클래스의 1500을 읽습니다.

표현이 예에서 읽거나 바꾸는 곳

E06 · 리스트는 어디에서 만들었는지 확인

class SharedBag:
    items = []

class OwnBag:
    def __init__(self):
        self.items = []

a = SharedBag()
b = SharedBag()
a.items.append("펜")
print(b.items)

c = OwnBag()
d = OwnBag()
c.items.append("책")
print(c.items, d.items)
실행 결과
['펜']
['책'] []

클래스 본문에 만든 items 리스트는 a와 b가 함께 찾는 하나의 리스트입니다. append는 그 리스트 자체를 고칩니다. __init__ 안에서 self.items = []로 만들면 객체마다 새 리스트를 가집니다.

상속은 기존 클래스의 속성과 메서드를 이어받아 쓰는 것입니다. class Dog(Animal)이면 Animal은 부모 클래스, Dog는 자식 클래스입니다. 자식에게 같은 이름의 메서드가 있으면 그 메서드를 쓰며, 이를 재정의(오버라이딩)라고 합니다.

class Dog(Animal):

Dog에는 kind가 없으므로 부모 Animal의 kind를 사용합니다. sound는 Dog에 다시 정의되어 있으므로 멍멍을 반환합니다.

E08 · super로 부모의 초기화 재사용

class Person:
    def __init__(self, name):
        self.name = name

class Student(Person):
    def __init__(self, name, score):
        super().__init__(name)
        self.score = score

student = Student("서진", 92)
print(student.name, student.score)
실행 결과
서진 92

이 단일 상속 예에서 super().__init__(name)은 부모 초기화를 실행해 name을 넣습니다. 이어서 자식이 score를 넣습니다. 자식이 __init__을 직접 정의하면 부모 __init__이 저절로 추가 실행되지 않습니다.

E09 · 부모 메서드 안에서도 자식의 재정의가 사용됨

class Message:
    def text(self):
        return "안녕"

    def show(self):
        return "[" + self.text() + "]"

class Notice(Message):
    def text(self):
        return "공지"

print(Notice().show())
실행 결과
[공지]

show는 부모에게서 가져오지만 self는 Notice 객체입니다. self.text()는 Notice가 재정의한 text를 호출합니다. “어느 클래스에 적힌 코드인가”와 “self가 어떤 객체인가”를 나누어 보세요.

E10 · 부모 계산을 쓰고 자식 계산 덧붙이기

class Order:
    def __init__(self, amount):
        self.amount = amount

    def total(self):
        return self.amount

class DeliveryOrder(Order):
    def total(self):
        return super().total() + 2500

print(Order(8000).total())
print(DeliveryOrder(8000).total())
실행 결과
8000
10500

DeliveryOrder는 부모의 __init__을 그대로 물려받습니다. total만 재정의하고, 이 단일 상속에서 super().total()로 부모 계산을 가져와 배송비 2500을 더합니다.

E11 · 객체 리스트를 함수에 전달하고 정렬

class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

def passed_names(students):
    passed = [s for s in students if s.score >= 60]
    ranked = sorted(passed, key=lambda s: (-s.score, s.name))
    return [s.name for s in ranked]

students = [Student("지수", 72), Student("민아", 90), Student("도현", 55)]
print(passed_names(students))
print([s.score for s in students])
실행 결과
['민아', '지수']
[72, 90, 55]

s는 학생 객체 하나입니다. s.score로 점수를 읽습니다. 함수·리스트 컴프리헨션·lambda는 17~18일차 내용이며, 리스트 안에 숫자 대신 객체가 들어간 것만 달라졌습니다.

E12 · 객체를 공유한 복사와 새 객체를 만든 복사

class Score:
    def __init__(self, value):
        self.value = value

original = [Score(40), Score(70)]
shallow = original[:]
separate = [Score(s.value) for s in original]
shallow[0].value += 5
separate[1].value += 10
print([s.value for s in original])
print([s.value for s in shallow])
print([s.value for s in separate])
실행 결과
[45, 70]
[45, 70]
[40, 80]

리스트만 복사한 shallow는 안쪽 Score 객체를 original과 함께 가리킵니다. separate는 Score(...)로 새 객체를 만들어 점수 변경이 분리됩니다. 여기서는 속성 값이 정수라 이 방식으로 충분합니다.

        return True

class Student:
    def __init__(self, name, group, score):
        self.name = name
        self.group = group
        self.score = score

def group_averages(students):
    groups = {}
    for student in students:
        if student.group not in groups:
            groups[student.group] = []
        groups[student.group].append(student.score)
    return {group: round(sum(scores) / len(scores), 1) for group, scores in groups.items()}

def rank_names(students):
    ranked = sorted(students, key=lambda s: (-s.score, s.name))
    return [student.name for student in ranked]

students = [Student("나래", "A", 70), Student("가람", "A", 90), Student("다온", "B", 90)]

class Task:

        self.priority = priority
        self.done = False

    def score(self):
        return self.priority

class UrgentTask(Task):
    def score(self):
        return super().score() + 100

def pending_numbers(tasks):
    pending = [task for task in tasks if not task.done]
    ordered = sorted(pending, key=lambda t: (-t.score(), t.number))
    return [task.number for task in ordered]

def complete(task):
    task.done = True

tasks = [Task(1, 80), UrgentTask(2, 5), Task(3, 80)]
print(pending_numbers(tasks))
complete(tasks[1])
