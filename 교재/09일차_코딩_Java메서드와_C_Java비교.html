배열 길이는 a.length, 문자열 길이는 s.length()입니다. String 내용 비교에는 equals를 사용합니다. 반복해서 쓴 계산 코드를 이름 붙은 작업으로 묶으면 Java에서는 메서드, C에서는 함수로 부릅니다. 오늘의 Java 코드는 모두 같은 Main 클래스 안에서 static 메서드끼리 호출합니다.

1. 쉬운 설명 · 작업대에 입력을 주고 결과 받기

메서드는 이름 붙인 작은 작업대입니다. 인자는 호출할 때 실제 넣는 값이고 매개변수는 작업대 안에서 입력을 받을 칸입니다. return은 계산값을 호출한 자리로 돌려보내고 그 호출을 끝냅니다. 화면 출력과 반환은 다른 일입니다.

static int price(int count) {
    return count * 1300;
}
// static: 이 예에서는 객체를 만들지 않고 호출하는 클래스 메서드
// int: 반환형, price: 이름, int count: 매개변수
// price(3): 인자 3을 넣어 호출

메서드는 main의 중괄호 안이 아니라 Main 클래스 안, main 바깥에 정의합니다. 오늘은 객체 없이 부르기 위해 static을 붙입니다. static이라고 자동 실행되거나, 메서드의 모든 지역변수 값이 다음 호출에 남는 것은 아닙니다. 같은 클래스 안에서는 이름으로, 명확히 쓰면 Main.price(3)처럼 호출할 수 있습니다.

예제 E01 · 정의·호출·반환

언어 · Java

public class Main {
    static int price(int count) { return count * 1300; }
    public static void main(String[] args) {
        int total=price(3);
        System.out.println(total);
        price(2);
        System.out.println(total);
    }
}

실행 결과

3900
3900

첫 호출의 3900을 total에 저장합니다. 둘째 호출도 2600을 반환하지만 저장·출력하지 않아 total은 그대로입니다. 메서드를 정의만 해 둔 경우에는 본문이 실행되지 않습니다.

예제 E02 · 기본형은 값의 복사본

언어 · Java

public class Main {
    static int bonus(int score) {
        score+=6;
        return score;
    }
    public static void main(String[] args) {
        int score=70;
        int result=bonus(score);
        System.out.println(score+" "+result);
        score=bonus(score);
        System.out.println(score);
    }
}

실행 결과

70 76
76
시점main의 scorebonus의 score결과
첫 호출 직전70없음—
첫 호출 내부7070→7676 반환
첫 복귀 후70수명 끝result=76
두 번째 복귀 후76수명 끝반환값을 score에 재대입

Java도 C도 값 전달입니다. Java int의 값 70을 복사하므로 매개변수만 바꾸면 원본은 바뀌지 않습니다. 반환값을 원래 변수에 대입하면 그때 원본 변수가 바뀝니다. 호출 위치의 지역변수가 호출된 메서드 안으로 따라 들어가지는 않습니다.

예제 E03 · void와 조기 return

언어 · Java

public class Main {
    static void show(int n) {
        if(n<0) { System.out.println("INVALID"); return; }
        System.out.println(n*2);
    }
    public static void main(String[] args) {
        show(-2);
        show(4);
    }
}

실행 결과

INVALID
8

void는 반환값이 없다는 뜻입니다. return;은 값을 돌려주지 않고 메서드를 끝냅니다. void 호출을 int 변수에 저장할 수 없습니다. 반환형이 int라면 정상적으로 끝나는 모든 경로에서 int로 맞는 값을 반환해야 합니다.

2. 응용 설명 · 같은 이름, 다른 입력과 배열 처리

예제 E04 · 오버로딩은 입력 목록으로 구별

언어 · Java

public class Main {
    static int fee(int count) { return count*900; }
    static int fee(int count,int discount) { return count*900-discount; }
    public static void main(String[] args) {
        System.out.println(fee(3));
        System.out.println(fee(3,200));
    }
}

실행 결과

2700
2500

오버로딩은 같은 클래스에서 이름은 같지만 매개변수 목록이 다른 메서드를 정의하는 것입니다. 매개변수의 개수·타입·타입 순서로 구별합니다. 이름이 int a인지 int b인지, 반환형이 int인지 double인지만 다르게 해서는 구별할 수 없습니다. 반환값을 받을 변수의 타입으로 어느 메서드를 부를지 고르지 않습니다.

예제 E05 · 정확한 타입과 확대 변환

언어 · Java

public class Main {
    static String kind(int x) { return "int"; }
    static String kind(double x) { return "double"; }
    public static void main(String[] args) {
        System.out.println(kind(7));
        System.out.println(kind(7.0));
        System.out.println(kind((double)7));
    }
}

실행 결과

int
double
double

7은 int 리터럴, 7.0과 (double)7은 double이므로 해당 매개변수 버전을 선택합니다. 오늘은 기본형의 정확한 일치와 int→double 확대만 다룹니다. double 인자를 int 매개변수에 자동으로 좁히지는 않습니다. 오버로딩은 같은 이름의 여러 입력 형식이며, 상속에서 메서드를 재정의하는 오버라이딩과 다른 개념입니다.

두 선언가능 여부이유
f(int) / f(int,int)가능개수가 다름
f(int,double) / f(double,int)가능타입 순서가 다름
int f(int a) / int f(int b)불가능매개변수 이름만 다름
int f(int) / double f(int)불가능반환형만 다름

예제 E06 · 배열을 전달하면 참조의 값이 복사됨

언어 · Java

public class Main {
    static void add(int[] a) {
        for(int i=0;i<a.length;i++) a[i]+=3;
    }
    public static void main(String[] args) {
        int[] values={2,5,8};
        add(values);
        System.out.println(values[0]+" "+values[1]+" "+values[2]);
    }
}

실행 결과

5 8 11
호출 전 main의 values ───→ 배열 [2,5,8]
호출 중 main의 values ─┐
                      ├─→ 같은 배열
       add의 a ───────┘
a[i] 대입 → 같은 배열의 실제 원소 변경

배열 객체 전체가 복사되는 것은 아닙니다. main의 values에 든 참조 값이 매개변수 a로 복사됩니다. 두 참조가 같은 배열을 가리키므로 a[i]를 수정하면 main에서도 바뀐 원소를 봅니다. 이것을 “Java가 배열만 참조 전달한다”라고 외우면 다음 예제를 틀리기 쉽습니다.

예제 E07 · 매개변수 재대입은 원본 참조를 바꾸지 않음

언어 · Java

public class Main {
    static void reset(int[] a) {
        a[0]=20;
        a=new int[]{8,9};
        a[0]=99;
    }
    public static void main(String[] args) {
        int[] values={4,7};
        reset(values);
        System.out.println(values[0]+" "+values[1]);
    }
}

실행 결과

20 7
실행main의 valuesreset의 a관찰
호출 직후원래 배열원래 배열[4,7]
a[0]=20원래 배열원래 배열원래 배열 [20,7]
a=new int[]{8,9}원래 배열새 배열연결 대상 분리
a[0]=99원래 배열새 배열main은 여전히 [20,7]

매개변수 a 자체도 별도 변수입니다. a=새 배열은 그 복사본의 참조만 바꿉니다. 호출자도 새 배열로 바꾸려면 메서드에서 배열을 반환하고 values=make();처럼 받아야 합니다.

예제 E08 · 새 배열 반환과 String 반환

언어 · Java

public class Main {
    static int[] make(int base) { return new int[]{base,base+1}; }
    static String label(String s) { return s+"!"; }
    public static void main(String[] args) {
        int[] a=make(10);
        String s="GO";
        label(s);
        System.out.println(a[0]+" "+a[1]+" "+s);
        s=label(s);
        System.out.println(s);
    }
}

실행 결과

10 11 GO
GO!

반환형 int[]는 배열의 참조 값을 반환합니다. Java의 new로 만든 배열은 메서드가 끝났다고 즉시 없어지는 지역 배열이 아닙니다. 반면 C 자동 지역 배열의 주소를 반환해 사용하면 수명이 끝난 공간에 접근하는 문제가 생깁니다. String은 불변이므로 label의 결과를 버리면 원래 s는 GO 그대로입니다.

예제 E10 · C는 정수의 주소를 전달해 원본 교환

언어 · C11

#include <stdio.h>
void swap(int *a,int *b) { int t=*a; *a=*b; *b=t; }
int main(void) {
    int x=6,y=17;
    swap(&x,&y);
    printf("%d %d\n",x,y);
    return 0;
}

실행 결과

17 6

C도 주소의 값이 복사되는 값 전달입니다. 복사된 주소를 역참조해 main의 정수를 바꿉니다. 일반 Java에서는 &x나 int* 같은 방식으로 정수 지역변수 주소를 넘기지 않습니다. Java에서는 원본 정수 두 개를 바꾸는 대신 결과를 돌려받거나 배열 원소를 교환할 수 있습니다.

예제 E11 · Java 배열 원소 교환

언어 · Java

public class Main {
    static void swapAt(int[] a,int i,int j) {
        int t=a[i]; a[i]=a[j]; a[j]=t;
    }
    public static void main(String[] args) {
        int[] a={6,17};
        swapAt(a,0,1);
        System.out.println(a[0]+" "+a[1]);
    }
}

실행 결과

17 6

예제 E12 · C 배열은 주소와 길이를 함께

언어 · C11

#include <stdio.h>
int sum(const int *a,int n) {
    int s=0;

    return s;
}
int main(void) {
    int a[]={3,7,11};
    int result=sum(a,3);
    printf("%d\n",result);
    return 0;
}

추적 규칙 · 메서드·함수마다 매개변수 칸을 따로 그립니다. 원소 변경과 참조·포인터 변수 재대입을 나눠 적으세요. C에서는 배열 범위를 넘거나 유효하지 않은 주소를 읽는 코드에 정해진 출력값을 붙이지 않습니다. 부작용이 있는 여러 호출은 서로 다른 문장으로 분리해 호출 순서를 확정합니다.

S01 · 점수 보정과 평균 분리

Java에서 void adjust(int[] a,int bonus), double average(int[] a)를 작성하세요. 0~100 점수에 0~10 보너스를 더하되 100 초과는 100으로 제한합니다. average는 빈 배열이면 0.0, 나머지는 실수 평균을 반환합니다.

[61,96,80]에 bonus=5 → [66,100,85], 평균은 251/3. 출력은 총점도 함께 확인합니다.
정답과 해설

알고리즘 · 보정은 같은 배열 원소를 수정하고 평균은 읽기만 합니다. 평균의 나누기 전에 double로 변환합니다.

언어 · Java

public class Main {
    static void adjust(int[] a,int bonus) {
     for(int i=0;i<a.length;i++) { a[i]+=bonus; if(a[i]>100) a[i]=100; }
    }
    static double average(int[] a) {
     if(a.length==0) return 0.0;
     int sum=0; for(int v:a) sum+=v;
     return (double)sum/a.length;
    }
    public static void main(String[] args) {
        int[] a={61,96,80};
        adjust(a,5);
        System.out.println(a[0]+" "+a[1]+" "+a[2]);
        System.out.println(average(a));
    }
}

83.66666666666667

경계 조건 · 빈 배열은 보정 없음·평균 0.0, [100]은 보정 후에도 100입니다. 입력 점수·보너스 범위를 지키세요.

S02 · 오버로딩한 결제 금액

Java에서 int total(int unit,int count), int total(int unit,int count,int discount)를 만드세요. 세 인자 버전은 두 인자 버전을 호출해 소계를 얻은 뒤 할인하고 0 미만이면 0을 반환합니다. 입력은 음수 아님, 계산은 int 범위 안입니다.

unit=1200,count=3 → 3600. discount=500이면 3100, discount=5000이면 0.
정답과 해설

알고리즘 · 중복 곱셈을 줄이기 위해 기본 메서드 호출 결과를 활용합니다. 할인 후 음수인지 검사하고 조기 반환합니다.

언어 · Java

public class Main {
    static int total(int unit,int count) { return unit*count; }
    static int total(int unit,int count,int discount) {
     int result=total(unit,count)-discount;
     if(result<0) return 0;
     return result;
    }
    public static void main(String[] args) {
        System.out.println(total(1200,3));
        System.out.println(total(1200,3,500));
        System.out.println(total(1200,3,5000));
    }
}

3100
0

경계 조건 · 수량 0이면 두 인자 결과는 0입니다. 세 인자 버전의 할인액이 소계와 같으면 0을 반환합니다.

S03 · 원본 보존 역순 배열

Java의 int[] reversed(int[] a)를 작성하세요. 새 배열을 만들고 역순으로 복사해 반환하되 원본은 바꾸지 않습니다. 빈 배열도 허용합니다.

[3,6,9,12] → 새 배열 [12,9,6,3], 원본은 [3,6,9,12]
정답과 해설

알고리즘 · 길이가 같은 새 배열 out을 만든 뒤 out[i]=a[length-1-i]로 채우고 반환합니다.

언어 · Java

public class Main {
    static int[] reversed(int[] a) {
     int[] out=new int[a.length];
     for(int i=0;i<a.length;i++) out[i]=a[a.length-1-i];
     return out;
    }
    public static void main(String[] args) {
        int[] a={3,6,9,12};
        int[] b=reversed(a);
        System.out.println(a[0]+" "+a[3]);
        System.out.println(b[0]+" "+b[3]+" "+(a==b));
    }
}
3 12
12 3 false

경계 조건 · 빈 입력은 길이 0인 새 배열, 한 원소는 같은 값의 새 배열입니다. 반환 배열의 원소를 바꿔도 원본은 바뀌지 않습니다.

S04 · 부분 구간 합계 API

Java의 int sumRange(int[] a,int from,int to)를 작성하세요. from 포함·to 제외 구간을 더합니다. 0<=from<=to<=a.length이고 합은 int 범위 안입니다.

[4,7,10,13], from=1,to=3 → 17. from=to이면 0.
정답과 해설

알고리즘 · i=from부터 i<to까지 순회합니다. API의 끝 제외 규칙을 먼저 적고 빈 구간도 같은 반복으로 처리합니다.

언어 · Java

public class Main {
    static int sumRange(int[] a,int from,int to) {
     int s=0;
     for(int i=from;i<to;i++) s+=a[i];
     return s;
    }
    public static void main(String[] args) {
        int[] a={4,7,10,13};
        System.out.println(sumRange(a,1,3));
        System.out.println(sumRange(a,2,2));
    }
}

0

S05 · 상태 변경 후 성공 개수 반환

Java int close(String[] status)를 작성하세요. 내용이 "OPEN"인 원소만 "CLOSED"로 교체하고 교체 수를 반환합니다. null·다른 문자열은 유지합니다.

["OPEN",null,new String("OPEN"),"WAIT"] → CLOSED,null,CLOSED,WAIT 및 반환 2
정답과 해설

알고리즘 · "OPEN".equals(status[i])로 null을 안전하게 검사합니다. 배열 원소를 교체하고 count를 누적합니다. String 내부 내용을 수정하는 것이 아닙니다.

언어 · Java

public class Main {
    static int close(String[] status) {
     int count=0;
     for(int i=0;i<status.length;i++) {
      if("OPEN".equals(status[i])) { status[i]="CLOSED"; count++; }
     }
     return count;
    }
    public static void main(String[] args) {
        String[] a={"OPEN",null,new String("OPEN"),"WAIT"};
        int count=close(a);
        System.out.println(count+" "+a[0]+" "+a[1]+" "+a[2]+" "+a[3]);
    }
}
2 CLOSED null CLOSED WAIT

경계 조건 · 빈 배열은 0, 전부 null이면 0입니다. 같은 배열에 두 번 호출하면 둘째 반환은 0이어야 합니다.

S06 · C와 Java로 같은 위치 교환

같은 배열 [8,3,15]의 인덱스 0과 2를 교환하세요. Java는 swapAt(int[] a,int i,int j), C는 swapAt(int *a,int i,int j)로 작성합니다. 인덱스는 유효하다고 가정합니다.

두 언어 모두 [15,3,8]. 정수 인자 두 개만 받는 Java swap으로 바꾸면 원본 원소는 교환되지 않습니다.
정답과 해설

알고리즘 · 임시변수에 a[i] 값을 보관하고 a[i]=a[j], a[j]=temp 순서로 실행합니다. 언어별 전달되는 값의 정체를 그림으로 설명하세요.

언어 · Java

public class Main {
    static void swapAt(int[] a,int i,int j) { int t=a[i]; a[i]=a[j]; a[j]=t; }
    public static void main(String[] args) {
        int[] a={8,3,15};
        swapAt(a,0,2);
        System.out.println(a[0]+" "+a[1]+" "+a[2]);
    }
}
15 3 8

언어 · C11

#include <stdio.h>
void swapAt(int *a,int i,int j) { int t=a[i]; a[i]=a[j]; a[j]=t; }
int main(void) {
    int a[]={8,3,15};
    swapAt(a,0,2);
    printf("%d %d %d\n",a[0],a[1],a[2]);
    return 0;
}

경계 조건 · i==j이면 값이 그대로입니다. 두 번 같은 위치를 교환하면 원본 순서로 돌아옵니다.
