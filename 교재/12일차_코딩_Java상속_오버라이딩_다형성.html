1. 쉬운 설명 · 상속은 “한 종류” 관계

자전거와 자동차는 둘 다 탈것입니다. 공통 행동을 Vehicle에 넣고 Bus 같은 구체적인 종류를 만들 때 extends를 씁니다. 자식 객체를 만들면 부모 부분부터 준비되므로 부모 생성자가 먼저 실행됩니다.

class Vehicle {
    String label;
    Vehicle(String label) {
        this.label = label;
        System.out.println("부모 생성");
    }
    void move() { System.out.println(label + " 이동"); }
}
class Bus extends Vehicle {
    Bus(String label) {
        super(label);
        System.out.println("자식 생성");
    }
}
public class Main {
    public static void main(String[] args) {
        Bus bus = new Bus("7번 버스");
        bus.move();
    }
}
부모 생성
자식 생성
7번 버스 이동

super(label)은 부모 생성자를 부르며 자식 생성자에서 첫 문장이어야 합니다. 부모에게 매개변수 없는 생성자가 있으면 super()가 암묵적으로 호출됩니다. 부모가 Vehicle(String)만 갖고 있다면 자식에서 super(label)을 명시해야 합니다.

2. 응용 설명 · 같은 메서드 이름, 실제 객체에 맞는 실행

자식이 부모의 인스턴스 메서드를 같은 매개변수 목록으로 다시 만들면 오버라이딩입니다. 부모 타입 변수로 자식 객체를 가리키는 업캐스팅을 해도, 재정의된 메서드는 실제 자식 객체의 것이 실행됩니다.

class Notice {
    String text() { return "기본 알림"; }
}
class EmailNotice extends Notice {
    @Override String text() { return "이메일 알림"; }
}
public class Main {
    public static void main(String[] args) {
        Notice n = new EmailNotice();
        System.out.println(n.text());
    }
}
이메일 알림

참조 변수 n의 타입은 Notice이지만 실제 객체는 EmailNotice입니다. 부모 타입으로 사용할 수 있는 메서드인지 먼저 컴파일 때 확인하고, 재정의된 메서드의 실행 본체는 실제 객체가 결정합니다.

3. 심화 설명 · 필드 접근과 메서드 호출은 기준이 다르다

자식이 부모와 같은 이름의 필드를 선언하면 필드는 숨겨집니다. 필드는 참조 변수의 선언 타입으로 고르고, 재정의한 인스턴스 메서드는 실제 객체로 고릅니다. 시험의 출력 추적에서 자주 섞이는 부분입니다.

class Parent {
    int value = 10;
    String say() { return "부모"; }
}
class Child extends Parent {
    int value = 20;
    @Override String say() { return "자식"; }
}
public class Main {
    public static void main(String[] args) {
        Parent p = new Child();
        System.out.println(p.value);
        System.out.println(p.say());
    }
}
10
자식

같은 이름의 필드를 부모·자식 양쪽에 두는 설계는 혼동을 일으키므로 실제 개발에서는 피하는 편이 좋습니다. 다만 출력 추적 문제에서는 p.value와 p.say()의 기준이 다름을 확인하세요.

class Parent {
    String show(Object x) { return "부모 Object"; }
    String show(String x) { return "부모 String"; }
}
class Child extends Parent {
    @Override String show(Object x) { return "자식 Object"; }
}
public class Main {
    public static void main(String[] args) {
        Parent p = new Child();
        System.out.println(p.show("hi"));
        System.out.println(p.show(3));
    }
}
부모 String
자식 Object

첫 호출은 String 인수에 더 맞는 show(String)를 먼저 고르며, 자식이 그 메서드를 재정의하지 않았으므로 부모 구현을 실행합니다. 둘째는 Integer가 Object에 들어가 show(Object)를 고르고, 실제 Child 객체의 재정의 구현을 실행합니다. 오버로딩 선택을 먼저, 오버라이딩 실행을 나중에 보세요.

제작 P01

배송 요금 계산

제작 P03

쿠폰 할인

Coupon에 할인액 필드와 discount(price)를 만드세요. FixedCoupon은 고정액, RateCoupon은 비율로 계산하되 할인액이 가격을 넘지 않게 하세요.

예시 구현과 확인
class Coupon {
    int discount(int price){return 0;}
}
class FixedCoupon extends Coupon {
    int amount;
    FixedCoupon(int amount){this.amount=amount;}
    @Override int discount(int price){return Math.min(price,amount);}
}
class RateCoupon extends Coupon {
    int percent;
    RateCoupon(int percent){this.percent=percent;}
    @Override int discount(int price){return price*percent/100;}
}
public class Main {
    public static void main(String[] args){
        Coupon[] cs={new FixedCoupon(2000),new RateCoupon(10)};
        for(Coupon c:cs)System.out.println(10000-c.discount(10000));
    }
}

최종 가격 8000, 9000이 출력됩니다. 할인 계산을 같은 메서드로 요청합니다.

제작 P04

학생 성적 보정

Student의 score()를 HonorsStudent에서 재정의해 보너스 점수를 더하세요. super.score()를 사용하고 부모·자식 생성 순서를 출력하세요.

예시 구현과 확인
class Student {
    int raw;
    Student(int raw){this.raw=raw;System.out.println("기본 성적 저장");}
    int score(){return raw;}
}

    int bonus;
    HonorsStudent(int raw,int bonus){
        super(raw);this.bonus=bonus;System.out.println("보너스 저장");

public class Main {
    public static void main(String[] args){
        Student s=new HonorsStudent(75,5);
        System.out.println(s.score());
    }
}

기본 성적 저장, 보너스 저장, 80이 출력됩니다.

게임 캐릭터 공격

Character에 이름과 attack()을 만들고 Knight·Wizard가 다른 공격 문장을 반환하게 하세요. 한 배열에서 모든 공격을 실행하세요.

제작 P06

파일 용량 안내

FileItem에 kb 필드와 display()를 만들고 ImageFile에서 display()를 재정의하세요. 부모와 자식 참조로 접근할 때 필드·메서드 차이를 직접 출력해 확인하세요.

예시 구현과 확인
class FileItem {
    int kb=100;
