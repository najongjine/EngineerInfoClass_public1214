1. 쉬운 설명 · 값과 순서를 먼저 적기

문자열은 한 글자씩, 리스트는 한 칸씩 번호를 붙입니다. 슬라이싱의 끝 번호는 포함하지 않습니다. set은 중복을 없애지만 출력 순서에 기대면 안 됩니다.

E01 · 문자열을 나누고 필요한 값만 모으기

text = " red / blue / red "
words = [word.strip() for word in text.split("/")]
unique = sorted(set(words))
print(words)
print("-".join(unique))
실행 결과
['red', 'blue', 'red']
blue-red

split으로 나누기 → strip으로 앞뒤 공백 지우기 → set으로 중복 제거 → sorted로 순서를 정하기 → join으로 연결합니다.

E06 · 부모의 흐름에서 자식 계산 호출

class Ticket:
    def price(self):
        return 4000

    def receipt(self):
        return self.price() + 1000

class ChildTicket(Ticket):
    def price(self):
        return super().price() // 2

receipt의 self는 ChildTicket 객체입니다. self.price() → 자식 price → 부모 가격 4000의 절반 2000 → receipt에서 1000 추가 → 3000입니다.

P02 · 성적 자료의 독립 복사

학생별 점수 목록을 복사하고, 복사본 점수를 고쳐도 원본을 유지하세요. 점수는 0~100의 정수입니다.

  • Student(name, scores)는 전달받은 점수 리스트를 복사해 저장.
  • average()는 소수점 한 자리로 반올림한 평균 반환. 점수가 없으면 None.
  • clone()은 같은 이름과 점수의 새 Student 반환. 객체와 점수 리스트가 모두 별개여야 함.
class Student:
    def __init__(self, name, scores):
        pass
    def average(self):
        pass
    def clone(self):
        pass

original = Student("서진", [60, 80])
copied = original.clone()
copied.scores[0] = 100
print(original.scores, original.average())
print(copied.scores, copied.average())
정답과 풀이 열기

완성 예

class Student:
    def __init__(self, name, scores):
        self.name = name
        self.scores = scores[:]

    def average(self):
        if not self.scores:
            return None
        return round(sum(self.scores) / len(self.scores), 1)

    def clone(self):
        return Student(self.name, self.scores)

original = Student("서진", [60, 80])
copied = original.clone()
copied.scores[0] = 100
print(original.scores, original.average())
print(copied.scores, copied.average())

실행 결과

[60, 80] 70.0
[100, 80] 90.0

clone이 새 객체를 만들고, __init__이 점수 리스트를 다시 복사합니다. 리스트 안이 정수인 이 경우에 맞는 복사입니다.

추가 확인 · 점수가 없으면 평균 None / 전달한 원본 리스트와 분리 / 복사본 점수 추가가 원본에 영향 없음

class Parcel:
    def __init__(self, weight):
        self.weight = weight

    def fee(self):
        return 1000 + self.weight * 500

class FragileParcel(Parcel):
    def fee(self):
        return super().fee() + 700

def bill(parcels, coupon):
    return max(0, sum(parcel.fee() for parcel in parcels) - coupon)

parcels = [Parcel(2), FragileParcel(1)]
print([p.fee() for p in parcels])
print(bill(parcels, 500))

def merge_orders(orders):
    result = {}
    for name, quantity in orders:
        if quantity > 0:
            result[name] = result.get(name, 0) + quantity
    return result

def top_names(orders, n):
    if n <= 0:
        return []
    totals = merge_orders(orders)
    ranked = sorted(totals.items(), key=lambda x: (-x[1], x[0]))
    return [name for name, quantity in ranked[:n]]

orders = [("pen", 2), ("book", 1), ("pen", 3), ("eraser", 5), ("book", 0)]
print(merge_orders(orders))
print(top_names(orders, 2))

class Node:
    def __init__(self, name, size):
        self.name = name
        self.size = size
        self.children = []

def total_size(node):
    if node is None:
        return 0
    return node.size + sum(total_size(child) for child in node.children)

root = Node("자료", 0)
photo = Node("사진", 0)
photo.children = [Node("a.jpg", 40), Node("b.jpg", 60)]
root.children = [Node("memo.txt", 10), photo]
print(total_size(root))

사진 부분은 40+60=100, 자료 전체는 0+10+100=110입니다. 자식이 없으면 sum의 빈 합이 0이 되어 반환을 마칩니다.

class Course:
    def __init__(self, name, capacity):
        self.name = name
        self.capacity = capacity
        self.students = []

    def enroll(self, student):
        student = student.strip()
        if not student or student in self.students or len(self.students) >= self.capacity:
            return False
        self.students.append(student)
        return True

    def cancel(self, student):
        student = student.strip()
        if student not in self.students:
            return False
        self.students.remove(student)
        return True

def snapshot(courses):
    return {course.name: course.students[:] for course in courses}

course = Course("Python", 2)
print(course.enroll("민지"), course.enroll("준호"), course.enroll("유나"))
saved = snapshot([course])
saved["Python"].append("복사본")
course.cancel("준호")
print(course.students)
print(saved["Python"])

실행 결과

True True False
['민지']
['민지', '준호', '복사본']

강좌 객체 → 리스트 변경 → 딕셔너리 결과 → 리스트 복사를 함께 사용합니다. saved는 취소 전 명단의 복사본입니다.
