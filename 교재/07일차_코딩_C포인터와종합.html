시작 확인

void f(int x) { x = 30; }을 f(n);으로 호출하면 main의 n은 바뀌지 않습니다. 값이 복사되기 때문입니다. 오늘은 “원본을 찾아갈 주소”를 복사해 넘기는 방법을 배웁니다.

1. 쉬운 설명 · 집 주소와 집 안의 물건

변수를 집이라고 생각해 봅시다. 주소는 집의 위치이고 값은 집 안 물건입니다. 포인터는 물건 자체가 아니라 주소를 담는 별도의 변수입니다. 주소를 알아야 그 집 안 물건을 읽거나 바꿀 수 있습니다.

표현뜻주의
int x = 12;정수 칸 x에 12 저장x는 실제 값
int *p = &x;정수의 주소를 담는 p를 만들고 x의 주소 저장선언의 *는 포인터 자료형을 나타냄
&xx의 주소주소 연산자
pp에 저장된 주소p 자체도 별도 변수
*pp가 가리키는 정수 칸식 안의 *는 역참조
&p포인터 변수 p 자신의 주소x의 주소와 다름
변수 칸             연결                 값
p [ x의 주소 ] ───────────────────→ x [ 12 ]

*p = 25;   // x에 25 저장
p = &y;    // 연결 대상을 y로 변경. x의 값은 바뀌지 않음

예제 E01 · 원본 변경과 포인터 이동은 다르다

#include <stdio.h>
#include <stddef.h>

int main(void) {
int x = 12, y = 40;
int *p = &x;
*p = 25;
p = &y;
*p += 3;
printf("%d %d\n", x, y);
return 0;
}

처음 *p는 x입니다. 25를 저장한 뒤 p에 y의 주소를 대입하면, 이후 *p는 y가 됩니다. x는 25로 남고 y만 40→43이 됩니다. 메모리 주소의 구체적인 숫자는 실행마다 달라질 수 있어 정답으로 외우지 않습니다. 주소를 확인할 때는 printf("%p", (void *)p);를 사용합니다.

예제 E02 · 주소도 값으로 복사된다

#include <stdio.h>
#include <stddef.h>
void bonus(int *score) { *score += 7; }
int main(void) {
int n = 60;
bonus(&n);
printf("%d\n", n);
return 0;
}

main은 n의 주소를 넘깁니다. bonus의 score에는 그 주소의 복사본이 생깁니다. 복사된 주소도 같은 n을 가리키므로 *score를 바꾸면 원본 n이 바뀝니다. C는 여기서도 값 전달입니다. “포인터면 참조 전달로 언어 규칙이 바뀐다”라고 외우지 마세요.

예제 E03 · 값 교환에는 임시 보관함이 필요하다

#include <stdio.h>
#include <stddef.h>
void swap(int *a, int *b) { int t = *a; *a = *b; *b = t; }
int main(void) {
int a = 9, b = 22;
swap(&a, &b);
printf("%d %d\n", a, b);
return 0;
}
실행abt
시작922—
t = *a (함수 매개변수 a가 가리킨 원본)9229
*a = *b22229
*b = t2299
위 표의 a·b 열은 main의 원본 정수입니다. 함수의 a·b는 주소를 담는 별도 매개변수입니다. 이름이 같다고 같은 칸은 아닙니다. int *p, q;에서 p만 포인터이고 q는 정수입니다. 처음에는 int *p;와 int *q;처럼 따로 선언하세요.

2. 응용 설명 · 배열, 문자열, 구조체

배열은 같은 자료형의 칸이 이어진 구조입니다. 대부분의 식에서 배열 이름은 첫 원소를 가리키는 포인터로 변환됩니다. a[i]는 *(a+i)와 같습니다. 단, 배열과 포인터 변수는 같은 물건이 아닙니다. 배열 이름 자체에 다른 주소를 대입할 수 없습니다.

int a[4] = {6, 12, 18, 24};
int *p = a + 1;

인덱스       0      1      2      3      4
배열 값     [6]   [12]   [18]   [24]   끝 다음
                   ↑p             ↑a+3   ↑a+4
*p == 12     *(p+2) == 24     p-a == 1
a+4는 만들고 비교할 수 있지만 *(a+4)는 읽거나 쓸 수 없음

p+1은 1바이트가 아니라 p가 가리키는 자료형의 원소 하나만큼 이동합니다. int가 몇 바이트인지 외워서 주소를 계산할 필요가 없습니다. 포인터 뺄셈은 같은 배열 안의 두 위치(끝 다음 포함) 사이에서 원소 개수 차이를 구할 때 사용합니다. 결과 자료형은 ptrdiff_t이고 출력 형식은 %td입니다.

예제 E04 · 함수에 배열을 넘길 때 길이도 넘긴다

#include <stdio.h>
#include <stddef.h>
void raise_all(int *a, int n) {
 for (int i=0; i<n; i++) a[i] += 2;
}
int main(void) {
int a[] = {6, 12, 18};
raise_all(a, 3);
printf("%d %d %d\n", a[0], a[1], a[2]);
return 0;
}

함수 매개변수의 int a[]는 int *a로 조정됩니다. 함수는 배열 전체를 복사받지 않고 첫 원소의 주소를 받습니다. 길이가 자동으로 따라오지 않으므로 n도 함께 전달합니다. main의 실제 배열에는 sizeof(a)/sizeof(a[0])를 쓸 수 있지만 포인터 매개변수에 같은 식을 쓰면 배열 길이가 나오지 않습니다.

예제 E05 · 문자열의 끝과 변경 가능한 공간

#include <stdio.h>
#include <stddef.h>

int main(void) {
char word[] = "TRAIN";
char *p = word + 2;
printf("%s %c\n", p, *p);
*p = 'O';
printf("%s\n", word);
return 0;
}

word는 T R A I N 그리고 널 문자 \0을 담는 6칸 배열입니다. %s는 현재 위치부터 \0 직전까지 출력하므로 p는 AIN을 출력합니다. %c는 한 글자 A입니다. 배열 word는 수정할 수 있지만 const char *s = "TRAIN";처럼 문자열 리터럴을 가리키는 경우 그 문자를 바꾸면 안 됩니다. 읽기 전용 문자열은 const로 선언하세요.

예제 E06 · 구조체 포인터와 화살표

#include <stdio.h>
#include <stddef.h>
struct Student { int id; int score; };
void add(struct Student *s) { s->score += 4; }
int main(void) {
struct Student a[] = {{11, 72}, {12, 85}};
struct Student *p = a + 1;
add(p);
printf("%d %d %d\n", p->id, (*p).score, a[0].score);
return 0;
}

p->score는 (*p).score와 같습니다. p가 가리킨 구조체의 score입니다. p.score는 p가 구조체 자체가 아니라 포인터이므로 사용할 수 없습니다. 구조체 포인터도 p+1이면 다음 구조체 한 개로 이동합니다.

3. 심화 설명 · 가리키는 대상과 실행 순서

포인터 문제는 “지금 어디를 가리키는가?”와 “지금 그 칸의 값은 무엇인가?”를 따로 적으면 풀립니다. 같은 주소를 가진 두 포인터를 통한 변경은 같은 원본에 반영됩니다. 포인터 매개변수에 다른 주소를 대입하는 일은 호출자의 포인터 변수를 바꾸는 일과 다릅니다.

예제 E07 · 포인터를 옮겨도 호출자의 포인터는 그대로

#include <stdio.h>
#include <stddef.h>
void touch(int *p) {
 *p += 1;
 p++;
 *p += 10;
}
int main(void) {
int a[] = {3, 6, 9};
int *p = a;
touch(p);
printf("%d %d %d\n", *p, a[1], a[2]);
return 0;
}
시점main의 ptouch의 p배열
호출 직후a[0]a[0]3, 6, 9
*p += 1 후a[0]a[0]4, 6, 9
p++ 후a[0]a[1]4, 6, 9
마지막 변경 후a[0]a[1]4, 16, 9

헷갈리는 세 표현

표현동작예: p가 a[0]을 가리키면
*p++*(p++): 현재 원소 값을 사용한 뒤 포인터 이동사용한 값은 a[0], 이후 p는 a[1]
(*p)++가리키는 값 증가, 포인터 위치 유지a[0]의 값이 1 증가
*++p먼저 포인터 이동, 이동한 곳의 값 사용p가 a[1]로 이동하고 a[1] 읽음

후위 ++의 결과는 증가 전 값이고, 증가는 해당 전체 식이 끝나기 전 완료됩니다. 한 printf 인자 목록에서 p를 바꾸면서 다른 인자로 p를 읽는 식은 만들지 않습니다. 예: printf("%d %d", *p++, *p);에는 정해진 출력 답을 붙이면 안 됩니다. 변경 문장과 출력 문장을 나누세요.

 return 1;
}

void swap(int *a, int *b) { int t = *a; *a = *b; *b = t; }
void sort(int *a,int n) {
 for(int i=0;i<n-1;i++) {
  int m=i;
  for(int j=i+1;j<n;j++) if(a[j]<a[m]) m=j;
  if(m!=i) swap(a+i,a+m);
 }
}

int a[]={13,4,9,1}; sort(a,4);

정답과 해설

① p는 주소, *p는 그 주소의 대상입니다. ② 주소의 값이 복사되며 원본 주소를 통해 대상에 접근합니다. ③ 포인터가 가리키는 자료형 원소 하나 기준입니다. ④ 널 문자 직전입니다. ⑤ (*p).x입니다.
