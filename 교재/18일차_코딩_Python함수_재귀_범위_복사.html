1. 쉬운 설명 · 호출한 곳으로 돌아온다

def는 함수 정의입니다. 정의할 때는 안쪽 내용을 실행하지 않습니다. 함수이름(...)으로 호출해야 실행합니다. 함수 안으로 들어간 코드에는 공백 네 칸을 들여 씁니다.

E01 · 정의와 호출은 다르다

def greet():
    print("함수 안")

print("시작")
greet()
print("끝")
실행 결과
시작
함수 안
끝

greet를 정의하고, 시작을 출력하고, greet()를 호출합니다. 함수 안을 실행한 뒤 다음 줄인 끝으로 돌아옵니다.

매개변수는 함수가 전달받은 값을 부르는 이름입니다. add(4, 7)의 4와 7이 def add(a, b)의 a와 b에 연결됩니다. return은 값을 돌려주고 함수를 끝냅니다.

E02 · print와 return 구별

def add(a, b):
    return a + b

def show(a, b):
    print(a + b)

x = add(4, 7)
print(x * 2)
y = show(4, 7)
print(y)
실행 결과
22
11
None

add는 11을 반환해 x에 저장합니다. show는 11을 화면에 출력하지만 return 값은 없습니다. 값을 돌려주지 않은 함수의 반환값은 None입니다. None은 “반환한 값이 없음”으로 읽습니다.

코드하는 일
print(value)화면에 출력
return value호출한 곳에 값을 전달하고 함수 종료
return값 없이 함수 종료. 반환값은 None
함수 끝까지 도달return이 없으면 None 반환

E03 · 함수 안 이름과 바깥 이름

x = 10
def local():
    x = 30
    print("안", x)

def change_global():
    global x
    x += 2

local()
print("밖", x)
change_global()
print("변경", x)
실행 결과
안 30
밖 10
변경 12

local 안의 x는 지역변수입니다. 바깥 x와 별개의 이름입니다. global x는 이 함수에서 바깥 x에 대입하겠다는 선언입니다. 변수 이름이 같다는 이유만으로 같은 변수가 되지 않습니다.

E04 · 정수 매개변수에 다시 대입

def increase(n):
    n += 5
    return n

value = 12
result = increase(value)
print(value, result)
value = increase(value)
print(value)
실행 결과
12 17
17

함수 안 n을 17에 연결해도 바깥 value가 저절로 바뀌지 않습니다. 반환값을 value에 다시 대입한 마지막 호출에서 바깥 value가 바뀝니다.

2. 응용 설명 · 전달된 리스트가 바뀌는 경우

함수는 전달된 객체를 함께 가리킬 수 있습니다. a[0] = 9는 그 리스트의 내부를 고치고, a = [9]는 함수 안 이름 a가 다른 리스트를 가리키게 합니다. 어느 쪽인지 구별합니다.

E05 · 칸 수정과 새 리스트 대입

def edit(a):
    a[0] = 9
    a.append(7)

def rebind(a):
    a = [0, 0]

items = [2, 4]
edit(items)
print(items)
rebind(items)
print(items)
실행 결과
[9, 4, 7]
[9, 4, 7]

edit의 a와 바깥 items가 같은 리스트를 가리켜 수정이 보입니다. rebind는 함수 안 a만 새 리스트를 가리키므로 items에는 영향이 없습니다.

함수 안 코드전달한 원래 리스트에 영향
a.append(7), a[0] = 9같은 리스트의 내부를 변경
a = [9], a = a + [7]새 리스트를 함수 안 이름에 대입. 원래 리스트는 그대로
a += [7], a[:] = [9]리스트 내부를 변경하므로 원래 리스트에도 반영

E06 · 기본값과 여러 값 반환

def price(total, discount=0):
    return total - discount

def summary(values):
    return sum(values), len(values)

print(price(5000), price(5000, discount=800))
total, count = summary([3, 8, 10])
print(total, count)
실행 결과
5000 4200
21 3

discount를 생략하면 기본값 0을 씁니다. return으로 쉼표로 묶어 반환한 값은 튜플이며, total과 count로 나누어 받을 수 있습니다.

E07 · 리스트를 바꾸지 않는 함수

def add_bonus(scores, bonus):
    result = []
    for score in scores:
        result.append(score + bonus)
    return result

scores = [61, 78, 90]
revised = add_bonus(scores, 3)
print(scores)
print(revised)
실행 결과
[61, 78, 90]
[64, 81, 93]

결과를 담을 새 리스트를 만들었습니다. scores의 각 칸에 대입하지 않아 원래 점수는 그대로입니다.

3. 심화 설명 · 재귀·복사·짧은 함수

재귀는 함수가 자기 자신을 호출하는 것입니다. 먼저 멈추는 조건을 확인합니다. 그다음 인수가 어떻게 줄어드는지 보고, 호출한 함수가 돌아온 뒤 남은 계산을 합니다.

E08 · 재귀 합계 · 돌아오면서 더하기

def total(n):
    if n == 0:
        return 0
    return n + total(n - 1)

print(total(4))
실행 결과
10

입력은 0 이상의 정수입니다. total(4)는 4+total(3)의 결과를 기다립니다. total(0)이 0을 반환하면 1·3·6·10 순서로 계산해 돌아옵니다.

호출할 때돌아올 때
total(4) = 4 + total(3)4 + 6 = 10
total(3) = 3 + total(2)3 + 3 = 6
total(2) = 2 + total(1)2 + 1 = 3
total(1) = 1 + total(0)1 + 0 = 1
total(0)에서 멈춤0 반환

E09 · print가 호출 앞인지 뒤인지

def trace(n):
    if n == 0:
        return
    print("들어감", n)
    trace(n - 1)
    print("돌아옴", n)

trace(2)
실행 결과
들어감 2
들어감 1
돌아옴 1
돌아옴 2

trace(2)가 trace(1)을 기다리고, trace(1)이 trace(0)을 기다립니다. 멈춘 뒤에는 가장 나중에 호출된 쪽부터 돌아옵니다. 호출 앞 print는 2→1, 호출 뒤 print는 1→2입니다.

E10 · 중첩 리스트 · 바깥만 복사한 것과 행도 복사한 것

original = [[2, 4], [6, 8]]
outer_copy = original[:]
row_copy = [row[:] for row in original]
outer_copy[0][0] = 99
row_copy[1][0] = 77
print(original)
print(outer_copy)
print(row_copy)
실행 결과
[[99, 4], [6, 8]]
[[99, 4], [6, 8]]
[[2, 4], [77, 8]]

original[:]는 바깥 리스트만 새로 만듭니다. 안쪽 행은 original과 공유합니다. row[:]를 행마다 실행하면 이 예제처럼 숫자만 든 2차원 리스트의 각 행도 복사됩니다. 더 깊은 중첩까지 모두 복사하려면 copy.deepcopy를 씁니다.

lambda는 짧은 함수를 한 줄로 쓰는 문법입니다. lambda x: x + 1은 x를 받아 x+1을 반환합니다. sorted(data, key=...)의 key에는 “어떤 값으로 비교할지 알려주는 함수”를 넣습니다.

E11 · 정렬 기준 함수

data = [("가", 78), ("나", 92), ("다", 85)]
ordered = sorted(data, key=lambda item: item[1], reverse=True)
print(data)
print(ordered)
실행 결과
[('가', 78), ('나', 92), ('다', 85)]
[('나', 92), ('다', 85), ('가', 78)]

item은 튜플 하나입니다. item[1]은 점수입니다. reverse=True이므로 높은 점수부터 나옵니다. sorted는 새 리스트를 돌려주므로 data는 그대로입니다.

E12 · 함수를 정렬 기준으로 전달

def length(word):
    return len(word)

words = ["pear", "fig", "plum", "kiwi"]
print(sorted(words, key=length))
print(sorted(words, key=lambda word: (len(word), word)))
실행 결과
['fig', 'pear', 'plum', 'kiwi']
['fig', 'kiwi', 'pear', 'plum']

key=length는 함수 자체를 전달합니다. 첫 줄에서 길이가 같은 pear·plum·kiwi는 원래 순서를 유지합니다. 둘째 줄은 길이가 같으면 단어 순으로 비교합니다. 튜플 기준은 앞 값부터 비교합니다.

sorted는 새 리스트를 반환하고, 리스트의 sort()는 그 리스트를 정렬한 뒤 None을 반환합니다. 재귀는 종료 조건뿐 아니라 입력 범위도 확인합니다. 이하 재귀 문제의 입력은 문제에 적힌 범위만 사용합니다.

P05 · 회문 판별기

def is_palindrome(text):
    if len(text) <= 1:
        return True
    if text[0] != text[-1]:
        return False
    return is_palindrome(text[1:-1])

def rank(records):
    return sorted(records, key=lambda row: (-row[1], row[0]))

P07 · 문자열을 품목별 합계로

aggregate(text)를 작성하세요. 상품:수량을 |로 구분한 문자열에서 상품별 합계 dict를 반환합니다. 빈 행은 무시하며 이름·수량 양끝 공백을 허용합니다. 나머지는 올바른 형식, 수량은 0 이상의 정수입니다.

시작 데이터
text = "펜:2|노트:3| 펜 :4||"
목표 출력
{'펜': 6, '노트': 3}
바꿔서 확인할 입력기대 출력
text = ''
{}
text = '펜:0|펜:0'
{'펜': 0}
정답과 풀이 열기
def aggregate(text):
    result = {}
    for row in text.split("|"):
        if row.strip():
            name, qty = row.split(":")
            name = name.strip()
            result[name] = result.get(name, 0) + int(qty)
    return result
text = "펜:2|노트:3| 펜 :4||"
print(aggregate(text))

P08 · 2차원 좌석 예약 · 원본 유지

reserve(seats, row, col)을 작성하세요. 0은 빈 좌석, 1은 예약입니다. 범위 밖이거나 이미 예약이면 (False, 원본)을, 성공하면 (True, 행까지 복사한 새 좌석표)를 반환합니다. seats는 직사각형의 2차원 리스트이며 빈 리스트도 허용합니다.

def reserve(seats, row, col):
    if row < 0 or row >= len(seats):
        return False, seats
    if col < 0 or col >= len(seats[row]):
        return False, seats
    if seats[row][col] == 1:
        return False, seats
    result = [line[:] for line in seats]
    result[row][col] = 1
    return True, result
seats = [[0, 1], [0, 0]]
row, col = 1, 0
ok, changed = reserve(seats, row, col)
print(ok, changed)
print(seats)
