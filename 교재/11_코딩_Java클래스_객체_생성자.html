1. 쉬운 설명 · 클래스와 객체

붕어빵 틀 하나로 붕어빵 여러 개를 만드는 것처럼 class 하나에서 객체를 여러 개 만듭니다. 필드는 객체 안에 저장하는 값, 메서드는 객체가 하는 일입니다. new를 실행할 때마다 별도 객체가 생깁니다.

class Lamp {
    String color;
    boolean on;
    void switchOn() { on = true; }
    void show() { System.out.println(color + ":" + on); }
}
public class Main {
    public static void main(String[] args) {
        Lamp desk = new Lamp(), bed = new Lamp();
        desk.color = "파랑"; bed.color = "노랑";
        desk.switchOn(); desk.show(); bed.show();
    }
}
파랑:true
노랑:false

desk와 bed는 다른 객체를 가리킵니다. desk.switchOn()은 desk의 on만 변경합니다. 필드는 기본값으로 초기화됩니다(int는 0, boolean은 false, 참조형은 null). 지역 변수에는 읽기 전에 직접 값을 넣어야 합니다.

2. 응용 설명 · 같은 객체를 가리키는 두 표지

참조 변수의 대입은 객체를 복사하지 않습니다. 같은 객체를 가리키는 표지 두 개라면 어느 쪽에서 필드를 바꿔도 같은 결과를 봅니다. ==는 참조가 동일한 객체를 가리키는지 검사합니다.

class Box { int value; }
public class Main {
    public static void main(String[] args) {
        Box a = new Box(); a.value = 4;
        Box b = a; b.value += 3;
        Box c = new Box(); c.value = 7;
        System.out.println(a.value + " " + (a == b) + " " + (a == c));
    }
}
7 true false

객체 배열의 칸에는 처음에 null이 들어갑니다. 배열을 만든 것과 각 칸의 객체를 만든 것은 다른 단계입니다.

class Ticket { int number; }
public class Main {
    public static void main(String[] args) {
        Ticket[] line = new Ticket[2];
        line[0] = new Ticket(); line[1] = new Ticket();
        line[0].number = 31; line[1].number = 42;
        System.out.println(line[0].number + line[1].number);
    }
}
73
line[0]이 null일 때 line[0].number에 접근하면 NullPointerException이 납니다. 참조 칸만 만든 상태인지 실제 객체까지 만들었는지 확인하세요.

3. 심화 설명 · 생성자와 this

생성자는 객체가 만들어질 때 첫 상태를 정합니다. 이름은 클래스와 같고 반환형은 없습니다. this는 지금 작업하는 바로 그 객체입니다. 매개변수와 필드의 이름이 같다면 this.name은 필드, name은 매개변수입니다.

class Member {
    String name; int points;
    Member(String name) { this(name, 0); }
    Member(String name, int points) {
        this.name = name; this.points = points;
    }
    void earn(int points) { this.points += points; }
    void show() { System.out.println(name + ":" + points); }
}
public class Main {
    public static void main(String[] args) {
        Member min = new Member("민", 5), jin = new Member("진");
        min.earn(3); jin.earn(2); min.show(); jin.show();
    }
}
민:8
진:2

this(name, 0)은 같은 클래스의 다른 생성자를 호출하며 반드시 첫 문장이어야 합니다. 생성자를 하나라도 직접 정의하면 매개변수 없는 기본 생성자는 자동으로 생기지 않습니다.

필드 변경과 참조 재대입의 차이

class Counter { int n; Counter(int n) { this.n = n; } }
public class Main {
    static void change(Counter x) {
        x.n += 2;             // 원본 객체의 필드 변경
        x = new Counter(100); // 지역 참조만 새 객체로 이동
        x.n++;
    }
    public static void main(String[] args) {
        Counter c = new Counter(5); change(c);
        System.out.println(c.n);
    }
}
7

Java 매개변수에는 참조값의 복사본이 전달됩니다. 같은 객체의 필드는 바꿀 수 있지만 메서드 안에서 참조를 재대입해도 호출자의 참조는 이동하지 않습니다.

제작 P01

도서 대출 장부

Book에 제목·총 권수·대출 권수를 저장하세요. borrow()는 남은 책이 있을 때만 대출 수를 늘립니다. 책 두 권을 만들어 각 상태를 출력하세요.

예시 구현과 확인
class Book {
    String title; int total, borrowed;
    Book(String title,int total){this.title=title;this.total=total;}
    boolean borrow(){if(borrowed>=total)return false;borrowed++;return true;}
    void show(){System.out.println(title+":"+(total-borrowed));}
}
public class Main {
    public static void main(String[] args){
        Book a=new Book("Java",2),b=new Book("SQL",1);
        a.borrow();a.borrow();System.out.println(a.borrow());b.borrow();
        a.show();b.show();
    }
}

false, Java:0, SQL:0이 출력됩니다. 대출 불가능할 때 상태가 바뀌지 않아야 합니다.

제작 P02

학생 평균표

Student에 이름과 점수 배열을 저장하고 average()를 구현하세요. 객체 배열에 학생 2명을 넣어 각각의 평균을 출력하세요.

예시 구현과 확인
class Student {
    String name; int[] scores;
    Student(String name,int[] scores){this.name=name;this.scores=scores;}
    double average(){int sum=0;for(int s:scores)sum+=s;return (double)sum/scores.length;}
}
public class Main {
    public static void main(String[] args){
        Student[] a={new Student("가",new int[]{70,80,90}),
                     new Student("나",new int[]{60,75,90})};
        for(Student s:a)System.out.println(s.name+":"+s.average());
    }
}

가:80.0, 나:75.0입니다. 빈 점수 배열은 허용하지 않는다는 입력 약속을 둡니다.

제작 P05

재고 창고

Product의 sell(int)는 수량이 양수이고 재고 이하일 때만 차감합니다. 성공 여부를 boolean으로 반환하세요.

예시 구현과 확인
class Product {
    String name; int stock;
    Product(String name,int stock){this.name=name;this.stock=stock;}
    boolean sell(int count){
        if(count<=0||count>stock)return false;
        stock-=count;return true;
    }
}
public class Main {
    public static void main(String[] args){
        Product p=new Product("연필",5);
        System.out.println(p.sell(3));
        System.out.println(p.sell(4));
        System.out.println(p.stock);
    }
}

true, false, 2입니다. 실패하면 재고가 그대로입니다.

제작 P07

버스 좌석 배정

Seat 객체 배열 3칸을 만들고 각 칸의 객체도 생성하세요. assign(name)은 빈 첫 좌석에 이름을 넣고, 꽉 차면 false를 반환합니다.

예시 구현과 확인
class Seat { String name; }
class Bus {
    Seat[] seats=new Seat[3];
    Bus(){for(int i=0;i<seats.length;i++)seats[i]=new Seat();}
    boolean assign(String name){
        for(Seat s:seats)if(s.name==null){s.name=name;return true;}
        return false;
    }
    void show(){for(Seat s:seats)System.out.println(s.name);}
}
public class Main {
    public static void main(String[] args){
        Bus b=new Bus();b.assign("가");b.assign("나");b.assign("다");
        System.out.println(b.assign("라"));b.show();
    }
}

false, 가, 나, 다입니다. 배열만 만들고 Seat 객체를 빼먹으면 오류가 납니다.

제작 P08

점수표 복사

ScoreCard에 add와 copy를 구현하세요. copy는 같은 점수로 새로운 객체를 만들어야 합니다. 원본과 복사본을 비교하세요.

예시 구현과 확인
class ScoreCard {
    int score;
    ScoreCard(int score){this.score=score;}
    void add(int n){score+=n;}
    ScoreCard copy(){return new ScoreCard(score);}
}
public class Main {
    public static void main(String[] args){
        ScoreCard a=new ScoreCard(10),b=a.copy();
        b.add(5);
        System.out.println(a.score+" "+b.score+" "+(a==b));
    }
}

10 15 false입니다. 참조만 복사한 것과 새 객체를 만든 차이를 확인합니다.
