기본형과 참조형 · 칸의 종류부터 정하기

변수는 값을 보관하는 이름 붙은 칸입니다. Java 기본형은 8개입니다. 정수 계산에는 우선 int, 실수 계산에는 double, 참·거짓은 boolean, 문자 하나는 char를 사용합니다. String과 배열은 기본형이 아니라 참조형입니다. 참조형 변수에는 객체를 찾아가는 참조가 저장됩니다. 오늘은 메모리 주소 숫자나 포인터 연산을 다루지 않습니다.

main 안의 지역변수는 값을 넣기 전에 읽으면 컴파일 오류입니다. 반면 new int[3]의 원소는 0으로 초기화됩니다. new boolean[2]는 false, new String[2]의 각 원소는 null입니다. null은 빈 문자열 ""과 다르며, null에 인스턴스 메서드를 호출하면 실행 중 오류가 납니다.

예제 E02 · 나누기와 형 변환

public class Main {
    public static void main(String[] args) {
        int a=9,b=4;
        System.out.println(a/b);
        System.out.println((double)a/b);
        System.out.println((double)(a/b));
        System.out.println(a%b);
    }
}

실행 결과

2
2.25
2.0
1

정수끼리 나누면 소수 부분을 버립니다. 나누기 전에 a를 double로 바꾸면 9.0/4가 되어 2.25입니다. 이미 9/4를 정수로 계산한 뒤 바꾸면 2.0이라 잃은 부분이 돌아오지 않습니다. double→int처럼 좁히는 변환은 명시적 형 변환이 필요하며, (int)3.8은 반올림이 아니라 3입니다.

곱셈·나눗셈은 덧셈보다 먼저이고, 같은 우선순위의 +는 왼쪽부터 계산합니다. 숫자+숫자는 덧셈, 문자열과 +로 만나는 값은 문자열 연결입니다. 두 번째 줄은 "점수:"+4가 먼저 문자열이 되므로 뒤의 7도 이어 붙습니다. 원하는 덧셈을 괄호로 먼저 계산하세요.

예제 E04 · 조건과 switch

public class Main {
    public static void main(String[] args) {
        int score=78;
        if(score>=80) System.out.println("A");
        else if(score>=60) System.out.println("B");
        else System.out.println("C");
        int menu=2;
        switch(menu) {
         case 1: System.out.print("X"); break;
         case 2: System.out.print("Y");
         default: System.out.println("Z");
        }
    }
}

실행 결과

B
YZ

if·else if는 위에서부터 검사하고 처음 참인 한 갈래만 실행합니다. switch의 case는 진입 위치입니다. 여기서 case 2에 break가 없어 default까지 이어집니다. 이 현상을 fall-through라고 합니다. 수업에서는 전통적인 case·break 문법을 사용합니다. 논리 연산 &&는 왼쪽이 false면 오른쪽을 평가하지 않고, ||는 왼쪽이 true면 오른쪽을 평가하지 않습니다.

2. 응용 설명 · 반복과 배열로 여러 값을 처리하기

예제 E05 · 반복문은 실행 순서를 적는다

public class Main {
    public static void main(String[] args) {
        int sum=0;
        for(int i=1;i<=4;i++) {
         if(i==2) continue;
         sum+=i;
        }
        System.out.println(sum);
        int x=0;
        do { x++; } while(x<0);
        System.out.println(x);
    }
}

실행 결과

8
1

for는 초기식→조건→본문→증감식→조건 순서입니다. continue는 현재 회전의 남은 본문을 건너뛰고 for의 증감식으로 갑니다. break는 가장 가까운 반복문을 끝냅니다. while은 먼저 조건을 검사하지만 do while은 본문을 먼저 실행하므로 최소 한 번 실행됩니다. do while 끝의 세미콜론도 필요합니다.

예제 E06 · 배열 길이와 누적

public class Main {
    public static void main(String[] args) {
        int[] scores={50,75,90,65};
        int sum=0,count=0;
        for(int i=0;i<scores.length;i++) {
         sum+=scores[i];
         if(scores[i]>=70) count++;
        }
        System.out.println(sum+" "+count);
        System.out.println((double)sum/scores.length);
    }
}

예제 E07 · 2차원 배열과 중첩 반복

public class Main {
    public static void main(String[] args) {
        int[][] a={{2,4,6},{3,5}};
        for(int r=0;r<a.length;r++) {
         int sum=0;
         for(int c=0;c<a[r].length;c++) sum+=a[r][c];
         System.out.println(sum);
        }
    }
}

실행 결과

12
8

Java의 2차원 배열은 각 행의 배열을 참조하는 배열입니다. 행 길이가 서로 다를 수 있습니다. a.length는 행 수 2, a[0].length는 3, a[1].length는 2입니다. 각 행 합계를 구하려면 sum=0을 바깥 반복의 본문에서 초기화해야 합니다. 모든 행을 합치려면 sum을 바깥 반복 이전에 두세요.

참조를 복사하면 같은 배열을 본다

int[] a={3,6};
int[] b=a;       // 원소 복사가 아니라 같은 배열의 참조 복사
b[0]=20;         // a[0]도 20으로 관찰됨
b=new int[]{8,9}; // b만 새 배열을 참조. a는 기존 배열 유지

향상된 for의 for(int v:a)에서 v는 매 회전 정수 원소 값의 복사본입니다. v를 바꿔도 원소는 바뀌지 않습니다. 배열 원소를 수정하려면 인덱스로 a[i]에 대입하세요. 실제 실행과 추적은 뒤의 연습문제에서 확인합니다.

3. 심화 설명 · String의 내용과 참조를 구별하기

String은 글자들의 내용을 표현하는 객체입니다. 기본형 int에 ==를 쓰면 숫자 값을 비교하지만, String 같은 참조형의 ==는 두 변수가 같은 객체를 가리키는지 확인합니다. 문자열 내용은 equals로 비교하세요. String의 equals는 대소문자도 구별합니다.

예제 E08 · 같은 내용과 같은 객체

public class Main {
    public static void main(String[] args) {
        String a="LAMP";
        String b=a;
        String c=new String(a);
        System.out.println(a==b);
        System.out.println(a==c);
        System.out.println(a.equals(c));
        System.out.println(a.equals("lamp"));
    }
}

실행 결과

true
false
true
false
a ──┐
    ├──→ String 객체 "LAMP"
b ──┘
c ─────→ 별도의 String 객체 "LAMP"
a==b: 같은 객체(true)
a==c: 다른 객체(false)
a.equals(c): 같은 내용(true)

같은 문자열 리터럴은 풀(pool)을 통해 공유될 수 있고 상수식 문자열도 공유될 수 있습니다. 그래서 ==가 우연히 true인 예만 보고 내용 비교에 사용하면 안 됩니다. new String(...)은 여기서 비교할 별도 String 객체를 만듭니다. String 내부 저장 구현이나 실제 메모리 주소는 출력 답의 근거로 쓰지 않습니다.

예제 E09 · String은 불변이다

public class Main {
    public static void main(String[] args) {
        String s="seed";
        s.toUpperCase();
        System.out.println(s);
        String t=s.replace("e","o");
        System.out.println(s+" "+t);
        s=s+"!";
        System.out.println(s);
    }
}

실행 결과

seed
seed sood
seed!

불변은 한 번 만들어진 String 객체의 내용이 바뀌지 않는다는 뜻입니다. toUpperCase나 replace는 결과 문자열을 반환하므로 그 결과를 받아야 합니다. s=s+"!"는 기존 객체의 글자를 고치는 것이 아니라, s가 결과 문자열을 참조하도록 재대입하는 일입니다. 모든 메서드가 항상 새 객체를 만든다고 외울 필요는 없습니다. 핵심은 원본 내용을 바꾸지 않는다는 점입니다.

S01 · 성적 요약표

빈 배열이 아닌 0~100 정수 점수 배열을 받아 총점, 실수 평균, 70점 이상 인원, 최댓값을 출력하세요.

[62,88,70,96] → 총점 316, 평균 79.0, 통과 3, 최고 96
정답과 해설

알고리즘 · sum=0, count=0, max=첫 점수로 시작합니다. 한 번 순회하면서 갱신하고 평균은 나누기 전에 double로 변환합니다.

public class Main {
    public static void main(String[] args) {
        int[] scores={62,88,70,96};
        int sum=0,pass=0,max=scores[0];
        for(int i=0;i<scores.length;i++) {
         sum+=scores[i];
         if(scores[i]>=70) pass++;
         if(scores[i]>max) max=scores[i];
        }
        double avg=(double)sum/scores.length;
        System.out.println(sum+" "+avg+" "+pass+" "+max);
    }
}

경계 조건 · [70]은 70·70.0·1·70입니다. [0,100]은 100·50.0·1·100입니다. 빈 배열은 입력 조건에서 제외합니다.

선택 연습

S02 · 거스름돈 계산기

0 이상의 10원 단위 금액을 1000·500·100·50·10원 단위로 나누고 각 개수를 출력하세요. 이 단위 체계에 대해서만 큰 단위부터 사용합니다.

2860 → 1000원 2개, 500원 1개, 100원 3개, 50원 1개, 10원 1개
정답과 해설

알고리즘 · 단위 배열을 큰 순서로 순회합니다. 금액/단위로 개수를 얻고 금액%=단위로 남은 금액을 갱신합니다.

public class Main {
    public static void main(String[] args) {
        int money=2860;
        int[] units={1000,500,100,50,10};
        for(int unit:units) {
         int count=money/unit;
         money%=unit;
         System.out.println(unit+":"+count);
        }
    }
}

S03 · 좌석 현황 집계

각 칸이 0(빈자리) 또는 1(사용 중)인 2차원 배열에서 행별 빈자리 수와 전체 빈자리 수를 출력하세요. 행 길이는 달라도 되고 빈 행도 허용합니다.

[[1,0,0],[0,1],[1,1,0]] → 행별 2·1·1, 전체 4
정답과 해설

알고리즘 · 바깥 반복마다 행별 count를 0으로 초기화합니다. 안쪽은 seats[r].length까지 돌고 0이면 행별·전체 개수를 늘립니다.

public class Main {
    public static void main(String[] args) {
        int[][] seats={{1,0,0},{0,1},{1,1,0}};

        for(int r=0;r<seats.length;r++) {
         int count=0;
         for(int c=0;c<seats[r].length;c++) {
          if(seats[r][c]==0) { count++; total++; }
         }
         System.out.println("row"+r+":"+count);
        }
        System.out.println("total:"+total);
    }
}

S04 · 상태 문자열 집계

null이 섞일 수 있는 상태 배열에서 내용이 정확히 "DONE"인 항목 수를 세세요. 대소문자는 구별하고 빈 문자열과 null은 세지 않습니다.

["DONE","WAIT",null,new String("DONE"),"done"] → 2
정답과 해설

알고리즘 · 각 원소를 "DONE".equals(원소)로 비교합니다. 리터럴을 호출 대상으로 두어 null에서도 안전하게 검사합니다.

public class Main {
    public static void main(String[] args) {
        String[] status={"DONE","WAIT",null,new String("DONE"),"done"};
        int count=0;
        for(String s:status) if("DONE".equals(s)) count++;
        System.out.println(count);
    }
}

경계 조건 · 전부 null이면 0입니다. 새 String 객체여도 내용이 DONE이면 셉니다. ==로 바꾼 결과와 비교해 보세요.

선택 연습

S05 · 영문 문자열 뒤집기

null이 아닌 영문·숫자 문자열을 뒤에서부터 읽어 새 문자열로 만드세요. 원본은 유지하고 빈 문자열도 처리합니다.

"A7BC" → "CB7A". 원본은 "A7BC" 그대로
정답과 해설

알고리즘 · i=length()−1부터 0까지 감소시키며 charAt(i)를 결과 문자열 뒤에 붙입니다. 학습용 작은 문자열만 대상으로 합니다.

public class Main {
    public static void main(String[] args) {
        String text="A7BC";
        String result="";
        for(int i=text.length()-1;i>=0;i--) result=result+text.charAt(i);
        System.out.println(text);
        System.out.println(result);
    }
}
A7BC
CB7A

경계 조건 · ""는 반복 없이 ""가 됩니다. "K"는 "K"입니다. UTF-16 대리쌍을 쓰는 문자 처리는 범위 밖입니다. 긴 문자열에서는 반복 연결 비용 때문에 다른 도구를 선택할 수 있습니다.

선택 연습

S06 · 중복 없는 첫 등장 순서

정수 배열을 왼쪽부터 읽고 처음 나오는 값만 같은 순서로 출력하세요. Set 없이 반복·배열만 사용합니다.

[4,2,4,7,2,9] → 4 2 7 9
정답과 해설

알고리즘 · 현재 i 앞의 0~i−1에서 같은 값이 있는지 검사합니다. 있으면 seen=true 후 안쪽 반복만 종료하고, 없으면 출력합니다.

public class Main {
    public static void main(String[] args) {
        int[] a={4,2,4,7,2,9};
        boolean first=true;
        for(int i=0;i<a.length;i++) {
         boolean seen=false;
         for(int j=0;j<i;j++) {
          if(a[j]==a[i]) { seen=true; break; }
         }
         if(!seen) {
          if(!first) System.out.print(" ");
          System.out.print(a[i]); first=false;
         }
        }
        System.out.println();
    }
}
4 2 7 9

경계 조건 · 빈 배열은 빈 줄, [5,5,5]는 5만 출력합니다. 음수도 ==로 비교할 수 있습니다. 정렬하면 첫 등장 순서가 사라질 수 있으므로 원본 순서를 유지합니다.

6. 마지막 5분 · 설명할 수 있으면 통과

① 배열 length와 String length()를 구별해 쓰세요. ② 문자열 내용 비교는 무엇으로 하나요? ③ String이 불변인데 s=s+"!"가 가능한 이유는? ④ int[] b=a는 원소 복사인가요? ⑤ 정수 평균에서 소수가 필요하면 언제 형 변환하나요?

정답과 해설

① 배열은 a.length, 문자열은 s.length()입니다. ② equals입니다. ③ 원본 내용 변경이 아니라 변수 s의 참조를 결과 문자열로 바꿉니다. ④ 같은 배열을 가리키는 참조 복사입니다. ⑤ 나누기 전에 피연산자 하나를 double로 바꿉니다.
