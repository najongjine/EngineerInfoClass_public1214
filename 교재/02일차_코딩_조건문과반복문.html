02 · 기초 — if·else는 갈림길

쉬운 설명: 질문에 따라 한쪽 길을 고르기

“나이가18 이상인가?”에 참이면 if 안을, 거짓이면 else 안을 실행합니다. 중괄호는 선택된 길의 범위입니다. 선택한 블록이 끝나면 갈림길 밖의 다음 문장으로 모입니다. C의 조건에서0은 거짓,0이 아닌 값은 참입니다.

int age = 15;
if (age >= 18) {
    printf("ADULT\n");
} else {
    printf("YOUNG\n");
}
printf("END\n");

15>=18은 거짓입니다. YOUNG를 출력한 뒤 공통 문장 END를 출력합니다. 조건이 거짓이라고 프로그램 전체가 끝나는 것은 아닙니다.

응용: 정상 범위와 범위 밖을 나누기

int age = 120;
if (age < 0 || age > 120) { printf("INVALID\n"); }
else { printf("OK\n"); }

0~120을 정상 범위로 정했다면 잘못된 나이는 “0 미만 또는120 초과”입니다. 두 조건이 동시에 참일 필요가 없어 OR를 씁니다. -1·0·120·121 네 경계로 확인하세요.

심화: 대입·비교·세미콜론의 함정

if (x == 5)는 비교이고 if (x = 5)는 대입 후 저장한 값으로 조건을 판단합니다. 문법이 맞아 컴파일돼도 의도는 틀릴 수 있습니다. 또 if (조건);처럼 바로 세미콜론을 붙이면 빈 문장을 조건부로 실행합니다. 그 다음 블록이 조건과 무관하게 실행되는 버그를 만들 수 있습니다.

중괄호 습관

중괄호를 생략하면 바로 다음 한 문장만 조건에 속합니다. 중첩된 if의 else는 보통 가장 가까운, 아직 else가 없는 if에 연결됩니다. 처음에는 항상 중괄호를 쓰고 블록 경계를 들여쓰기와 함께 확인하세요.

03 · 응용 — 여러 조건의 순서

쉬운 설명: if 여러 개와 else if는 다르다

int n = 12;
if (n >= 10) { printf("A"); }
if (n >= 5) { printf("B"); }
printf("\n");

독립 if는 각각 검사하므로 A와 B가 모두 출력됩니다. 두 번째가 else if이면 앞 if가 참인 순간 연쇄의 나머지를 건너뛰므로 A만 출력됩니다.

응용: 등급은 높은 구간부터

int score = 86;
if (score >= 90) { printf("A\n"); }
else if (score >= 80) { printf("B\n"); }
else if (score >= 60) { printf("C\n"); }
else { printf("F\n"); }

86은90 이상이 아니지만80 이상입니다. 앞에서 거짓이었던 조건도 현재 구간의 의미를 만듭니다. B의 실제 구간은80~89입니다. >=60을 맨 앞에 쓰면95도 거기서 잡히는 오류가 생깁니다.

심화: 중첩과 논리 결합의 선택

int member = 1, points = 35;
if (member == 1) {
    if (points >= 30) { printf("USE\n"); }
    else { printf("SAVE\n"); }
} else { printf("JOIN\n"); }

회원 여부를 먼저 검사하고 회원일 때 포인트를 검사합니다. “회원이고 포인트30 이상일 때만 USE”만 필요하면 &&로 합칠 수 있지만, JOIN과 SAVE처럼 실패 이유를 나누려면 중첩 구조가 읽기 쉽습니다.

score>=90>=80선택

80거짓참B
89거짓참B

04 · switch — 값으로 메뉴 고르기

쉬운 설명: 하나의 정수 값과 case 비교

int menu = 2;
switch (menu) {
case 1: printf("OPEN\n"); break;
case 2: printf("CLOSE\n"); break;
default: printf("UNKNOWN\n"); break;
}

menu의 값을 보고 일치하는 case로 이동합니다. break는 switch 밖으로 나갑니다. 일치하는 case가 없으면 default가 있을 때 그 위치로 갑니다. default도 없으면 switch의 처리를 건너뜁니다. case에는 정수 상수 식을 사용하며 같은 switch 안의 중복 case 값은 허용되지 않습니다. 실수·문자열 비교용 분기가 아닙니다.

응용: 여러 case를 하나의 처리로 묶기

int code = 2;
switch (code) {
case 1:
case 2: printf("BASIC\n"); break;
case 3: printf("PLUS\n"); break;
default: printf("INVALID\n"); break;
}

1과2는 같은 BASIC 처리로 이어집니다. case 이름이 매 줄마다 다시 조건 검사되는 것은 아닙니다.

심화: break를 만나지 않으면 아래로 이어진다

int key = 2, result = 1;
switch (key) {
case 1: result += 10;
case 2: result += 4;
default: result *= 3;
}
printf("%d\n", result);

case2에서 result=5가 되고 break가 없어 default 아래 문장도 실행해15가 됩니다. 이를 fall-through라고 합니다. default도 진입 후에는 일반 문장 흐름의 위치입니다. 반복문 안의 switch에서 break를 만나면 가장 가까운 switch만 종료하고 반복은 계속될 수 있습니다.

05 · for — 정해진 범위를 반복하기

쉬운 설명: 시작→검사→본문→갱신→재검사

int sum = 0;
for (int i = 1; i <= 4; i++) {
    sum += i;
}
printf("%d\n", sum);

시작 int i=1은 한 번만 수행합니다. i<=4를 검사해 참이면 본문, 그 다음 i++, 다시 조건 검사입니다. i=5에서 거짓이 되어 빠져나옵니다. for 안에서 선언한 i는 그 반복문의 범위 밖에서 사용할 수 없습니다. 종료값을 보려면 i를 반복문 밖에 선언하세요.

본문의 i본문 전 sumsum+=i 후갱신 후 i
1012
2133
3364
46105

응용: 합계와 개수를 따로 누적하기

int sum = 0, count = 0;
for (int i = 1; i <= 9; i++) {
    if (i % 3 == 0) { sum += i; count++; }
}
printf("%d %d\n", sum, count);

더하는 것은3·6·9이므로 sum=18, count=3입니다. sum은 값의 총합, count는 항목의 수입니다. 두 변수를 반복문 안에서 매번0으로 초기화하면 이전 누적값을 잃습니다.

심화: 시작값·끝 조건·갱신 폭을 따로 보기

int i;
for (i = 2; i < 9; i += 3) { printf("%d ", i); }
printf("end=%d\n", i);

본문은2·5·8에서 세 번입니다. 갱신 후11은 조건이 거짓이라 본문에서 출력하지 않습니다. <와<=, 시작0과1, ++와+=2를 서로 섞어 외우지 말고 실제 방문 값을 적으세요.

06 · while·do while — 조건이 계속될 동안

쉬운 설명: while은 먼저 질문한다

int stock = 7, sold = 0;
while (stock >= 2) {
    stock -= 2;
    sold++;
}
printf("%d %d\n", stock, sold);

7→5→3→1로 줄어들어2개씩 세 번 처리합니다. 반복을 끝내려면 언젠가 조건이 거짓이 되도록 상태가 바뀌어야 합니다. stock을 갱신하지 않으면 끝나지 않을 수 있습니다.

응용: do while은 일단 한 번 처리한다

int n = 0, digits = 0;
do {
    digits++;
    n /= 10;
} while (n > 0);
printf("%d\n", digits);

0도 십진수 한 자리로 세고 싶습니다. 본문을 먼저 수행해 digits=1이 되고 그 뒤 조건을 검사합니다. do while의 마지막에는 세미콜론이 필요합니다.

심화: 진입 전 값과 종료 후 값을 구분하기

구조검사 위치처음부터 거짓이면
while(조건){본문}본문 전0회
do{본문}while(조건);본문 후1회
for(초기;조건;갱신){본문}각 본문 전0회

“최소 한 번”이 필요한가를 기준으로 고르세요. 처음 값이 유효하지 않으면 본문을 아예 실행하면 안 되는 상황에서는 무조건 do while을 고르면 위험합니다. 반복의 입력 범위와 종료 조건을 먼저 정합니다.

07 · break·continue — 끝내기와 건너뛰기

쉬운 설명: break는 반복 탈출

int sum = 0;
for (int i = 1; i <= 8; i++) {
    if (i == 4) { break; }
    sum += i;
}
printf("%d\n", sum);

i=4에서 나가므로4를 더하지 않습니다. 합은1+2+3=6입니다. break 뒤의 본문과 그 반복의 갱신도 거치지 않습니다.

응용: continue는 이번 회차의 나머지 본문 생략

int sum = 0;
for (int i = 1; i <= 6; i++) {
    if (i % 2 == 0) { continue; }
    sum += i;
}
printf("%d\n", sum);

짝수에서 합산을 생략하고 for의 i++로 이동합니다. 홀수1·3·5의 합9입니다. 반복 전체를 끝내는 break와 다릅니다.

심화: while의 continue와 갱신 위치

int i = 0, count = 0;
while (i < 5) {
    i++;
    if (i == 3) { continue; }
    count++;
}
printf("%d %d\n", count, i);

while의 continue는 조건 검사로 이동합니다. i++를 continue 뒤쪽에만 두면 i=3에 머무르는 실수를 할 수 있습니다. do while의 continue는 아래쪽 조건 검사로 갑니다. switch 안의 continue도 switch를 다시 고르는 것이 아니라 가장 가까운 반복문의 다음 진행 위치로 갑니다.

08 · 심화 — 중첩 반복과 상태 추적

쉬운 설명: 안쪽 반복을 끝낸 뒤 바깥 갱신

int count = 0;
for (int row = 1; row <= 2; row++) {
    for (int col = 1; col <= 3; col++) {
        count++;
    }
}
printf("%d\n", count);

row=1일 때 col=1·2·3을 끝내고 row를 늘립니다. row=2가 되면 col도1부터 다시 시작합니다. 본문을 방문한 (row,col)을 적으면 빠뜨리기 어렵습니다.

응용: 안쪽 횟수가 달라지면 더하기

int count = 0;
for (int row = 1; row <= 3; row++) {
    for (int col = 1; col <= row; col++) { count++; }
}
printf("%d\n", count);

각 row의 안쪽 횟수는1·2·3이어서 합6입니다. 바깥3×안쪽3=9라고 고정 곱셈하면 틀립니다.

심화: 가장 가까운 반복만 종료한다

int count = 0;
for (int row = 1; row <= 2; row++) {
    for (int col = 1; col <= 4; col++) {
        if (col == 3) { break; }
        count++;
    }
}
printf("%d\n", count);

매 row마다 col=1·2만 count를 늘립니다. 안쪽 break가 바깥 반복까지 자동 종료하지 않습니다. 모든 반복을 끝내야 하는 문제라면 상태 변수 등을 이용해 바깥 조건도 따로 정해야 합니다.

E01 · 합격 경계

2점: 일반화한 코드가 표의 모든 조건을 만족하고 이유를 설명함. 1점: 일부 조건만 만족. 0점: 미완성·무응답. 출력 숫자만 고정해 찍는 코드는 일반화한 해결이 아닙니다.

n은0~99999입니다. 각 십진 자릿수의 합을 구하세요. 문자열·배열은 쓰지 않습니다. 원본 n을 유지하고 작업용 변수 work를 사용하세요.

target은1~1000, daily는1~100입니다. 매일 같은 금액을 저축하여 목표 이상이 되는 최소 일수와 최종 잔액을 구하세요. 목표를 넘는 것도 허용합니다.
