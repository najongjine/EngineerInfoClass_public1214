Q006핵심 기출문장·분기·조건 커버리지

2025년 1회 실기 · 원문 14번 · PDF 10쪽
학습 항목 03 · 출처: 1. 2025년1회_정보처리기사실기 기출문제.pdf

다음에 제시된 코드를 이용하여 순서도의 번호 ①~⑥에 들어갈 알맞은 코드를 작성하고, 문장 커버리지로 구성할 테스트 케이스를 작성하시오. (5점)
int Main(int b[], int m, int x) {
    int a = 0;
    while (a < m || b[a] < x) {
        if (b[a] < 0)
            b[a] = -b[a];
        a++;
    }
    return 1;
}
문장 커버리지 기준 테스트 케이스: ① → ② → ( ) → ( ) → ( ) → ( ) → ( )
정답·풀이 핵심 보기

정답: ① int a = 0; ② a < m || b[a] < x ③ b[a] < 0 ④ b[a] = -b[a]; ⑤ a++; ⑥ return 1; 문장 커버리지: ① → ② → ③ → ④ → ⑤ → ② → ⑥

초기화, 반복 조건, if 조건, 음수의 부호 변경, 증가, 반환을 순서도의 위치에 대응한다. 제시된 경로는 ④를 포함하여 모든 문장을 적어도 한 번 거친다. 코드의 ||와 Main 표기는 원문 그대로 유지했다. 이 문항은 코드와 제어 흐름의 대응을 묻는 문제다.
