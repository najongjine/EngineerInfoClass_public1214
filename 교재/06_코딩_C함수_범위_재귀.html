시작 확인 · 1–5와 연결

① x = x + 3;은 오른쪽을 먼저 계산한 뒤 왼쪽에 저장합니다. ② 반복문 안의 같은 코드를 여러 번 썼다면 함수로 묶을 수 있습니다. ③ 구조체가 여러 값을 묶었다면, 함수는 여러 실행 문장을 하나의 이름으로 묶습니다.

1. 쉬운 설명 · 함수는 주문을 받아 결과를 돌려주는 작은 작업대

음료 자판기에 수량을 넣으면 가격을 계산해 줍니다. 함수도 비슷합니다. 매개변수는 작업대가 입력을 받을 칸, 인자는 호출할 때 실제 넣는 값, return은 결과를 호출한 자리로 보내는 문장입니다. 함수를 정의해 두기만 하면 실행되지 않습니다. 이름 뒤에 괄호를 붙여 호출해야 실행됩니다.

int price(int count);       // 선언: 사용법을 미리 알림
int price(int count) {      // 정의: 실제 작업 내용
    return count * 1200;
}
// price(3): 호출. 인자 3이 매개변수 count에 복사됨
부분뜻읽는 방법
int price반환형과 함수 이름정수 결과를 돌려주는 price
int count매개변수 선언입력 정수를 count라는 칸에 받음
price(3)호출3을 넣고 작업을 실행
return count * 1200;결과 반환과 함수 종료계산값을 보내고 호출 지점으로 복귀

예제 1 · 반환값은 반드시 받을 필요가 있을까?

#include <stdio.h>
int price(int count) { return count * 1200; }
int main(void) {
int total = price(3);
printf("%d\n", total);
price(2);
printf("%d\n", total);
    return 0;
}

첫 호출의 3600은 total에 저장합니다. 둘째 호출도 2400을 계산하지만 저장하거나 출력하지 않아 화면에는 나타나지 않습니다. return은 printf가 아닙니다. total을 다시 대입하지 않았으므로 3600이 유지됩니다.

예제 2 · void와 함수 선언

#include <stdio.h>
void line(void);
void line(void) { printf("---\n"); }
int main(void) {
line();
line();
    return 0;
}

void line(void)의 앞 void는 반환값 없음, 괄호 속 void는 입력 없음입니다. 반환값이 없는 함수에서도 return;으로 일찍 종료할 수 있습니다. 함수를 main 뒤에 정의하려면 main 앞에 선언을 둡니다. 매개변수 개수와 자료형, 반환형이 서로 맞아야 합니다.

예제 3 · 값 전달: 복사본에 도장을 찍어도 원본은 그대로

#include <stdio.h>
int addBonus(int score) {
    score += 5;
    return score;
}
int main(void) {
int score = 70;
int result = addBonus(score);
printf("%d %d\n", score, result);
score = addBonus(score);
printf("%d\n", score);
    return 0;
}
순서main의 scoreaddBonus의 score반환값
호출 전70아직 없음—
첫 호출 중7070 → 7575
첫 복귀 후70수명 끝result에 75 저장
둘째 복귀 후75로 대입수명 끝main의 score에 저장
C의 전달 방식은 값 전달입니다. 여기서는 int의 복사본을 바꿉니다. 원본 정수를 바꾸려면 오늘은 반환값을 다시 대입하세요. 배열을 함수에 전달하는 경우는 배열 전체가 복사되는 방식이 아니며, 주소와 함께 7번에 다룹니다.

2. 응용 설명 · 변수 이름보다 소속과 수명을 먼저 보자

범위(scope)는 이름을 사용할 수 있는 코드 구간, 수명은 저장 공간이 유지되는 기간입니다. 두 개는 같은 말이 아닙니다. 함수 안 지역변수는 바깥에서 이름으로 사용할 수 없고, 일반적인 자동 지역변수는 호출할 때마다 새로 생깁니다.

변수이름이 보이는 곳값이 유지되는 기간초깃값을 생략하면
자동 지역변수선언한 블록 내부해당 블록 실행 동안불확정 값: 읽기 전에 대입
파일 범위 전역변수보통 해당 선언 뒤 파일 범위; 지역 이름에 가려질 수 있음프로그램 실행 동안0
함수 내부 static 지역변수선언한 블록 내부프로그램 실행 동안0; 초기화는 한 번

예제 4 · 같은 이름, 서로 다른 칸

#include <stdio.h>
int level = 4;
int next(void) { level += 2; return level; }
int main(void) {
int level = 20;
int result = next();
printf("%d %d\n", level, result);
    return 0;
}

main의 level은 전역 level을 가립니다. 하지만 next 안에는 지역 level이 없으므로 전역 4를 6으로 바꿉니다. 호출한 곳의 지역변수가 다른 함수 안으로 따라 들어가지 않습니다.

예제 5 · 자동 지역변수와 static 지역변수

#include <stdio.h>
int ticket(void) {
    int a = 1;
    static int s = 1;
    a += 2;
    s += 2;
    printf("%d %d\n", a, s);
    return s;
}
int main(void) {
ticket();
ticket();
ticket();
    return 0;
}

자동 a는 호출마다 1로 시작하므로 늘 3입니다. s는 처음 한 번만 1로 초기화되고 이후 값이 남아 3→5→7이 됩니다. static이 붙어도 이 함수 바깥에서 s라는 이름을 사용할 수 있는 것은 아닙니다. 파일 범위 static의 의미는 다른 개념이며 오늘은 함수 내부 static만 다룹니다.

예제 6 · 함수를 연결해 계산하기

#include <stdio.h>
int subtotal(int count) { return count * 900; }
int pay(int money) {
    if (money >= 3000) return money - 300;
    return money;
}
int main(void) {
int amount = subtotal(4);
int result = pay(amount);
printf("%d %d\n", amount, result);
    return 0;
}

작업을 수량→소계→할인 결제로 나눴습니다. amount는 3600이고 pay가 받은 money는 복사본이므로 할인 후에도 amount는 3600입니다. 조기 return 뒤의 문장은 그 호출에서 실행되지 않습니다.

3. 심화 설명 · 재귀는 복귀할 자리를 남기고 작은 일을 맡기는 것

재귀 함수는 자기 자신을 다시 호출합니다. 먼저 종료 조건으로 더 맡기지 않을 순간을 정하고, 다시 호출할 때는 반드시 종료 조건에 가까워지게 해야 합니다. 각 호출은 자신만의 매개변수·일반 지역변수를 가지며, 호출한 함수는 결과가 돌아올 때까지 기다립니다. 대기 중인 호출은 스택처럼 나중 호출부터 끝납니다.

예제 7 · 호출과 복귀가 모두 보이는 합계

#include <stdio.h>
int sum(int n) {
    printf("in:%d\n", n);
    if (n == 0) return 0;
    int lower = sum(n - 1);
    printf("out:%d\n", n);
    return n + lower;
}
int main(void) {
int result = sum(3);
printf("sum=%d\n", result);
    return 0;
}
대기 중인 호출현재 할 일돌아오는 값
sum(3)3 + sum(2)를 기다림3 + 3 = 6
sum(2)2 + sum(1)을 기다림2 + 1 = 3
sum(1)1 + sum(0)을 기다림1 + 0 = 1
sum(0)종료 조건 만족0을 즉시 반환

표를 위에서 아래로 내려가며 호출하고, 아래에서 위로 올라가며 반환값을 계산합니다. 출력이 재귀 호출 앞에 있으면 내려갈 때 찍히고, 뒤에 있으면 올라올 때 찍힙니다. 종료 조건의 return 때문에 out:0은 출력되지 않습니다.

실수 방지 · 종료 조건만 쓰고 인자가 커지면 끝나지 않습니다. 깊은 재귀는 실행 환경의 스택 한도를 넘을 수 있습니다. static은 재귀 호출 사이에서도 공유되지만 매개변수는 호출별로 다릅니다. 반환형이 int인 함수는 실행 가능한 경로마다 알맞은 값을 반환하도록 작성하세요. 부작용이 있는 함수 두 개를 한 식에 섞지 말고 별도 문장으로 호출 순서를 확정하세요.

손으로 푸는 공통 절차

① main부터 시작한다. ② 인자를 계산해서 매개변수 칸에 복사한다. ③ 전역·호출별 지역·공유 static을 별도 표에 적는다. ④ return 값을 호출 자리로 옮긴다. ⑤ 출력한 값만 화면 답에 적는다. 재귀에서는 각 호출의 n과 “돌아와서 실행할 문장”을 남긴다.

6. 수업 종료 확인

스스로 설명할 질문정리
return과 printf는 어떻게 다른가?return은 호출 지점에 값을 전달하고 종료, printf는 화면 출력입니다.
int 매개변수를 바꾸면 원본도 바뀌는가?복사본만 바뀝니다. 반환값을 원본에 다시 대입해야 반영됩니다.
지역 static은 모든 함수에서 이름으로 접근하는가?아닙니다. 이름의 범위는 지역이지만 값의 수명은 프로그램 전체입니다.
재귀를 추적하는 두 방향은?호출은 종료 조건을 향해 내려가고 복귀는 대기 중인 호출을 거슬러 올라옵니다.
