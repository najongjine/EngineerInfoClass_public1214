쉬운 설명 · 계산과 실행 흐름

시험 후 복습 · 쉬운 설명

X01 · 나누기 전에 자료형을 확인

시험 후에 확인합니다. int끼리 나누면 소수 부분을 버린 정수 결과가 나옵니다. 나눈 뒤 double로 바꿔도 이미 사라진 소수 부분은 돌아오지 않습니다. 실수 평균을 구하려면 나누기 전에 (double)을 사용합니다.

int total = 23, count = 4;
printf("%d %.2f %.2f\n", total / count, (double)(total / count), (double)total / count);

실행 결과와 이유

5 5.00 5.75

23/4는 정수 5. 둘째는 그 5를 실수로 바꿉니다. 셋째만 23.0/4라서 5.75입니다.

X02 · 조건은 경계값과 검사 순서로 읽기

90 이상 A, 80 이상 B이면 큰 기준을 먼저 검사합니다. else if는 앞 조건이 거짓일 때만 확인합니다. 79·80·89·90처럼 조건이 바뀌는 바로 옆 숫자를 대입해 보면 실수를 찾기 쉽습니다.

int score = 90;
char grade;
if (score >= 90) grade = 'A';
else if (score >= 80) grade = 'B';
else grade = 'C';
printf("%c\n", grade);

실행 결과와 이유

A

90에서 첫 조건이 참이므로 A를 넣고 나머지 분기는 건너뜁니다. >=80을 먼저 두면 90도 B가 됩니다.

X03 · 반복문은 i와 누적값을 따로 추적

continue는 이번 본문의 남은 부분을 건너뛰고 다음 반복으로 갑니다. for에서는 증감식도 거칩니다. break는 가장 가까운 반복문 자체를 끝냅니다. 실행 횟수를 셀 때는 조건을 검사한 횟수와 본문을 실행한 횟수를 구별합니다.

int sum = 0;
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;
    sum += i;
}
printf("%d\n", sum);

실행 결과와 이유

12

sum은 0→1→3→3→7→12. i=3에서는 더하지 않지만 다음 i=4로 계속 진행합니다.

X04 · 배열에서 번호와 값을 혼동하지 않기

a[i]에서 i는 칸 번호, a[i]는 그 칸의 값입니다. 짝수 번호를 고르는 i%2==0과 짝수 값을 고르는 a[i]%2==0은 다른 조건입니다. 최댓값은 실제 원소 a[0]으로 시작하면 음수 배열도 처리할 수 있습니다.

int a[4] = {-5, -2, -8, -3};
int best = a[0], sum = 0;
for (int i = 0; i < 4; i++) {
    if (a[i] > best) best = a[i];
    if (i % 2 == 0) sum += a[i];
}
printf("%d %d\n", best, sum);

실행 결과와 이유

-2 -13

최댓값은 -2, 짝수 번호 0과 2의 값은 -5와 -8이라 합계 -13입니다.

X05 · 2차원 배열의 행·열을 한 칸씩

a[r][c]는 r행 c열입니다. 열 합계는 c를 고정하고 r을 바꿉니다. 행 합계는 반대입니다. 새 행이나 새 열의 합계를 구할 때마다 누적 변수를 0으로 시작해야 합니다.

int a[2][3] = {{2, 6, 4}, {5, 1, 9}};
for (int c = 0; c < 3; c++) {
    int sum = 0;
    for (int r = 0; r < 2; r++) sum += a[r][c];
    printf("%d ", sum);
}
printf("\n");

실행 결과와 이유

7 7 13

열 0은 2+5, 열 1은 6+1, 열 2는 4+9입니다. r과 c를 겉·속 변수로 그림에 표시하세요.

X06 · 문자열 길이·비교·복사 연결

char 배열의 문자열은 널 문자 '\0'에서 끝납니다. strlen은 널 앞의 바이트 수이고, strcmp는 내용이 같으면 0입니다. strcpy는 목적지에 널까지 복사하므로 공간이 길이+1 이상이어야 하고 영역이 겹치지 않아야 합니다. 예제는 한 바이트 영문만 사용합니다.

char name[10] = "PLANT";

X07 · 앞에서 바꾼 값을 다음 계산이 사용

배열을 제자리에서 갱신하면 뒤 계산이 원래 값이 아니라 변경된 앞 칸을 읽을 수 있습니다. 한 줄씩 실행한 뒤 배열 그림에 값을 덮어 적으면 추적하기 쉽습니다. 여러 문장에서 순서대로 바꾸는 예제를 사용하며 한 식에서 같은 변수를 불명확하게 여러 번 변경하는 문제는 다루지 않습니다.

int a[4] = {3, 2, 5, 1};
for (int i = 1; i < 4; i++) a[i] += a[i-1];
for (int i = 0; i < 4; i++) printf("%d ", a[i]);
printf("\n");

실행 결과와 이유

3 5 10 11

배열은 [3,2,5,1]→[3,5,5,1]→[3,5,10,1]→[3,5,10,11]입니다. 매번 갱신한 앞 값을 읽습니다.

X08 · 문자열로 보이는 범위와 저장 칸 구별

중간에 널을 넣으면 %s와 strlen은 그 자리에서 멈춥니다. 뒤쪽 칸이 저절로 지워지는 것은 아닙니다. 이 위치에서 선언한 char 배열의 sizeof는 전체 저장 바이트이고 문자열 길이와 다를 수 있습니다.

X09 · 구조체 복사 후 수정은 어느 카드인가

숫자와 내부 char 배열만 가진 같은 구조체형은 b=a로 멤버 값을 복사할 수 있습니다. 복사 뒤 b를 고쳐도 별도 변수 a는 그대로입니다. 구조체 배열에서 카드 전체를 옮기면 이름·점수가 함께 이동합니다. 포인터 멤버의 의미는 다음 주 범위입니다.

typedef struct { char name[10]; int score; } Student;

막힐 때만: 단계별 힌트
  1. c는 마지막 열 바로 전까지만 검사한다.
  2. 찾으면 두 칸을 바꾸고 안쪽 반복을 종료한다.

S06 · 누적값을 이용한 구간 합계

a={3,1,4,2,5}의 누적 합계를 별도 배열 prefix[5]에 만들고, 인덱스 left=1부터 right=3까지 포함한 합계를 구하세요. 마지막에 원본 a[3]도 출력하여 원본이 유지되는지 확인합니다. 0<=left<=right<5가 보장됩니다.

막힐 때만: 단계별 힌트
  1. prefix[0]=a[0]부터 시작한다.
  2. prefix[i]=prefix[i-1]+a[i]로 채운다.
  3. left가 0이면 prefix[right], 아니면 그 값에서 prefix[left-1]을 뺀다.
정답·해설 확인

실행 결과

풀이 prefix는 3,4,8,10,15. 1~3 합계는 10-3=7이고 원본 a[3]은 2입니다.

완성 코드 · main 내부

int a[5]={3,1,4,2,5},prefix[5]={0};
int left=1,right=3,result;
prefix[0]=a[0];
for(int i=1;i<5;i++) prefix[i]=prefix[i-1]+a[i];
if(left==0) result=prefix[right];
else result=prefix[right]-prefix[left-1];
printf("%d %d\n",result,a[3]);
