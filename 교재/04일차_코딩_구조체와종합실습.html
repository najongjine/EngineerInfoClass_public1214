쉬운 설명 · 학생 정보 카드부터 시작

쉬운 설명

X01 · 학생 한 명의 정보를 한 묶음으로

이름·점수·등급을 서로 다른 배열에 저장하면 번호를 맞춰 관리해야 합니다. 구조체는 관련 있는 서로 다른 자료형의 값을 한 사람의 정보 카드처럼 묶습니다. struct Student는 카드의 양식을 만드는 선언이고, struct Student s는 그 양식으로 실제 카드 한 장을 만드는 선언입니다. 양식만 선언했다고 학생 데이터가 생기는 것은 아닙니다. 구조체 선언 뒤에는 세미콜론을 씁니다.

struct Student {
    char name[12];
    int score;
    char grade;
};
struct Student s = {"Mina", 84, 'B'};
printf("%s %d %c\n", s.name, s.score, s.grade);

실행 결과와 추적

Mina 84 B

중괄호의 값은 멤버 선언 순서에 맞춥니다. name은 널까지 담을 char 배열, score는 int, grade는 문자 한 개입니다. 출력도 %s·%d·%c를 각각 맞춥니다.

쉬운 설명

X02 · 점 연산자로 멤버 읽고 고치기

s.score는 s라는 학생 카드의 score 칸입니다. 구조체 변수 이름 뒤에 점을 찍어 멤버를 선택합니다. score가 숫자이므로 대입·덧셈을 할 수 있고, grade는 문자이므로 작은따옴표로 값을 넣습니다. 오늘은 구조체 변수와 배열만 사용하며 -> 연산자나 구조체 포인터를 사용하지 않습니다.

struct Student { char name[12]; int score; char grade; };
struct Student s = {"Jin", 76, 'C'};
s.score += 9;
if (s.score >= 80) s.grade = 'B';
printf("%d %c\n", s.score, s.grade);

실행 결과와 추적

85 B

76+9를 score에 저장해 85가 됩니다. 조건이 참이어서 grade만 C에서 B로 바뀝니다. name은 그대로입니다.

쉬운 설명

X03 · 문자열 멤버는 배열 규칙 그대로

구조체 안의 char 배열도 03일차에 배운 배열입니다. 선언 후 s.name="Yuri"처럼 배열 전체를 대입할 수 없습니다. strcpy로 널까지 복사합니다. 이름 4바이트와 널 1바이트가 목적지 12칸 안에 들어가므로 아래 복사는 안전합니다. 예제 이름은 영문만 사용합니다. 한글은 글자 수와 바이트 수가 다를 수 있습니다.

struct Student { char name[12]; int score; };
struct Student s = {"Ara", 90};
strcpy(s.name, "Yuri");
s.name[0] = 'M';
printf("%s %zu\n", s.name, strlen(s.name));

실행 결과와 추적

Muri 4

Yuri를 복사한 뒤 0번 문자 Y만 M으로 고칩니다. 길이는 널 앞 4바이트입니다. 문자열 전체 복사와 한 문자 대입을 구별합니다.

쉬운 설명

X04 · typedef는 자료형의 별명

typedef struct { ... } Student;는 구조체 자료형에 Student라는 이름을 붙입니다. 이후에는 struct Student라고 반복하지 않고 Student s;라고 선언할 수 있습니다. 별명은 변수가 아닙니다. 기존 struct Student 형태와 typedef 형태를 섞지 말고 예제별 선언을 그대로 읽습니다.

typedef struct { char name[12]; int score; } Student;
Student a = {"Sol", 81};
Student b = {"Dan", 92};
printf("%s %d\n", a.name, b.score);

실행 결과와 추적

Sol 92

Student가 자료형, a와 b가 서로 다른 변수입니다. 두 카드의 값은 따로 관리합니다.

쉬운 설명

X05 · 구조체 배열은 카드 여러 장

Student list[3]은 학생 카드 세 장입니다. list[1]은 두 번째 학생 전체이고 list[1].score는 그 학생의 점수입니다. 먼저 배열 번호로 대상을 고른 뒤 점으로 멤버를 고릅니다. 유효한 학생 번호는 0,1,2입니다.

typedef struct { char name[12]; int score; } Student;
Student list[3] = {{"Ara", 68}, {"Bomi", 93}, {"Chan", 79}};
for (int i = 0; i < 3; i++)
    printf("%s:%d\n", list[i].name, list[i].score);

실행 결과와 추적

Ara:68
Bomi:93
Chan:79

i가 0→1→2로 바뀌면서 카드 한 장씩 읽습니다. list.score나 list[i][score]가 아니라 list[i].score입니다.

번호namescore접근 예
0Ara68list[0].name
1Bomi93list[1].score
2Chan79list[2].name
양식·변수·멤버 구별

Student는 자료형, list는 구조체 배열, list[1]은 두 번째 구조체, list[1].score는 그 카드의 숫자 칸입니다. 멤버를 각각의 칸으로 그려 보세요. 구조체의 메모리 크기가 멤버 크기의 단순 합이라고 가정하는 문제는 내지 않습니다. 실제 배치는 정렬·패딩의 영향을 받을 수 있습니다.

응용 설명 · 조건과 반복으로 여러 카드 처리

응용 설명

X06 · 구조체 배열의 합계와 평균

03일차의 정수 배열 합계와 같은 방법입니다. 다만 a[i] 대신 list[i].score를 더합니다. 평균은 (double)sum / 3처럼 나누기 전에 실수로 바꿉니다. 예제는 학생이 3명이라는 조건이 있으므로 0으로 나누는 일이 없습니다.

typedef struct { char name[12]; int score; } Student;
Student list[3] = {{"Ina", 72}, {"Jun", 85}, {"Kai", 90}};
int sum = 0;
for (int i = 0; i < 3; i++) sum += list[i].score;
printf("%d %.2f\n", sum, (double)sum / 3);

실행 결과와 추적

247 82.33

sum은 0→72→157→247입니다. 평균 82.333…을 소수 둘째 자리까지 출력하면 82.33입니다.

응용 설명

X07 · 조건에 맞는 학생만 선택하고 등급 바꾸기

반복문은 모든 학생을 방문하고, 조건문은 수정할 학생을 고릅니다. 90점 이상 A, 80점 이상 B, 나머지 C라면 큰 경계값부터 검사합니다. else if를 사용하면 학생 한 명에게 한 등급만 결정합니다.

typedef struct { char name[12]; int score; char grade; } Student;
Student a[3] = {{"Ari", 90, '?'}, {"Bo", 80, '?'}, {"Cu", 79, '?'}};
for (int i = 0; i < 3; i++) {
    if (a[i].score >= 90) a[i].grade = 'A';
    else if (a[i].score >= 80) a[i].grade = 'B';
    else a[i].grade = 'C';
    printf("%s:%c\n", a[i].name, a[i].grade);
}

실행 결과와 추적

Ari:A
Bo:B
Cu:C

90은 A, 80은 B, 79는 C입니다. 조건 순서를 80부터 잡으면 90점이 B 분기에 들어갈 수 있습니다.

응용 설명

X08 · 이름으로 찾은 뒤 그 학생만 수정

문자열 멤버의 내용 비교도 strcmp를 사용합니다. 같을 때 반환값이 0입니다. 찾은 위치를 인덱스로 저장하면 다음 줄에서 그 구조체의 숫자 멤버를 고칠 수 있습니다. 못 찾은 위치 -1로 배열을 읽으면 안 되므로 반드시 found != -1을 확인합니다.

typedef struct { char name[12]; int score; } Student;
Student list[3] = {{"Ara", 70}, {"Bomi", 81}, {"Chan", 88}};
int found = -1;
for (int i = 0; i < 3; i++) {
    if (strcmp(list[i].name, "Bomi") == 0) { found = i; break; }
}
if (found != -1) list[found].score += 5;
printf("%d %d\n", found, list[1].score);

실행 결과와 추적

1 86

Bomi는 인덱스 1입니다. 81에 5를 더해 86이 됩니다. 못 찾았을 때는 수정문을 실행하지 않습니다.

응용 설명

X09 · 점수 대신 최우수 학생의 위치 기억

이름과 점수를 함께 보여주려면 최댓값만 기억하는 것보다 최고 학생의 위치 best를 기억하면 편합니다. list[i].score가 list[best].score보다 클 때 best를 i로 바꿉니다. 같은 점수면 앞 학생을 유지하도록 >를 사용합니다.

typedef struct { char name[12]; int score; } Student;
Student list[3] = {{"Ari", 91}, {"Bo", 96}, {"Cu", 96}};
int best = 0;
for (int i = 1; i < 3; i++)
    if (list[i].score > list[best].score) best = i;
printf("%d %s %d\n", best, list[best].name, list[best].score);

실행 결과와 추적

1 Bo 96

best는 0→1로 바뀌고, Cu는 같은 96이므로 바뀌지 않습니다. >=라면 동점 때 뒤 학생으로 바뀝니다.

i현재 점수검사 전 best현재 최고 점수검사 후 best
1960911
2961961

X09 추적표입니다. best에는 점수가 아니라 학생 번호를 넣습니다. 현재 값을 이전 최고와 비교하고, 동점일 때 갱신할지 조건으로 결정합니다.

심화 설명 · 복사·교환과 중첩 배열

심화 설명

X10 · 구조체 전체 대입은 내부 배열도 복사

같은 구조체 자료형의 변수끼리는 b=a;로 멤버 값을 복사할 수 있습니다. 오늘 사용하는 구조체에는 숫자와 내부 char 배열만 있으므로 이름 배열의 내용도 복사됩니다. 이후 b의 멤버를 바꿔도 a는 그대로입니다. 단독 배열 name2=name1은 허용되지 않는다는 사실과 구별합니다. 포인터 멤버를 가진 경우의 의미는 다음 주에 배웁니다.

typedef struct { char name[12]; int score; } Student;
Student a = {"Mina", 80};
Student b = a;
b.score = 99;
b.name[0] = 'J';
printf("%s %d | %s %d\n", a.name, a.score, b.name, b.score);

실행 결과와 추적

Mina 80 | Jina 99

b는 별도의 구조체 변수입니다. b.name의 M을 J로 바꿔도 a.name은 Mina이고 a.score는 80입니다.

심화 설명

X11 · 카드 전체를 교환해야 이름과 점수가 같이 이동

점수만 교환하면 이름과 점수의 짝이 깨집니다. 구조체 임시 변수 temp에 한 장을 보관하고 구조체 전체를 교환하면 내부 이름과 숫자가 함께 움직입니다. 임시 보관 → 첫 칸에 둘째 카드 → 둘째 칸에 보관한 카드 순서입니다.

typedef struct { char name[12]; int score; } Student;
Student list[2] = {{"Ari", 71}, {"Bo", 94}};
Student temp = list[0];
list[0] = list[1];
list[1] = temp;
printf("%s:%d %s:%d\n", list[0].name, list[0].score, list[1].name, list[1].score);

실행 결과와 추적

Bo:94 Ari:71

점수 94가 Bo와 함께 앞으로 옮겨집니다. 이름만 원래 위치에 남는 문제가 없습니다.

심화 설명

X12 · 구조체 멤버가 배열인 경우

구조체 배열의 각 학생 안에 과목 점수 배열을 둘 수도 있습니다. list[r].score[c]는 r번 학생의 c번 과목입니다. 바깥 반복은 학생, 안쪽 반복은 과목입니다. list[r] 자체도 배열이 아니라 학생 카드 한 장이라는 점을 구별합니다.

typedef struct { char name[12]; int score[2]; } Student;
Student list[2] = {{"Ina", {70, 90}}, {"Jun", {85, 95}}};
for (int r = 0; r < 2; r++) {
    int sum = 0;
    for (int c = 0; c < 2; c++) sum += list[r].score[c];
    printf("%s:%d\n", list[r].name, sum);
}

실행 결과와 추적

Ina:160
Jun:180

r=0에서는 70+90, r=1에서는 85+95입니다. sum은 학생이 바뀔 때마다 다시 0으로 시작합니다.

  1. 각 학생의 grade를 ?로 초기화한다.
  2. 반복 한 번으로 등급·합계·인원을 갱신한다.

막힐 때만: 단계별 힌트
  1. 필요 수량은 target-stock이다.
  2. 부족한 경우만 수량×단가를 합계에 더한다.

완성 코드 · main 내부

typedef struct { char name[12]; int stock; int target; int price; } Item;
Item a[3] = {{"pen",2,5,700},{"book",7,5,2000},{"cup",0,3,1200}};
int cost = 0;
for (int i = 0; i < 3; i++) {
    if (a[i].stock < a[i].target) {
        int need = a[i].target - a[i].stock;
        cost += need * a[i].price;
        a[i].stock = a[i].target;

}
