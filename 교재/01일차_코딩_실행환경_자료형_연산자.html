02 · 기초 — 코드를 쓰면 어떻게 화면에 나타날까?

우리가 쓰는 C 코드는 컴퓨터가 바로 실행하는 명령과 다릅니다. 편집기는 글을 쓰는 도구, 컴파일러는 C 규칙을 검사하고 실행 가능한 코드로 바꾸는 도구, 터미널은 실행 명령과 결과를 주고받는 창입니다. 편집기를 설치했다고 컴파일러가 자동으로 준비되는 것은 아닙니다.

① 편집·저장
hello.c→② 컴파일·링크
hello.exe 생성→③ 실행
화면 출력

Windows PowerShell과 GCC가 준비된 환경을 기준으로 합니다. 경로 혼동을 줄이려면 실습 폴더에서 터미널을 여세요. 파일 확장자가 실제로 .c인지 확인합니다. 파일이 hello.c.txt라면 이름을 고칩니다. 

gcc --version
gcc -std=c11 -Wall -Wextra hello.c -o hello.exe
.\hello.exe

첫 명령은 GCC가 있는지 확인합니다. 두 번째 명령은 파일을 검사하고 실행 파일을 만듭니다. -std=c11은 C11 기준, -Wall -Wextra는 자주 놓치는 실수를 경고하도록 하는 옵션입니다. 세 번째 명령이 실행입니다. 다른 IDE를 쓰면 같은 코드를 콘솔용 C 프로젝트에 넣고 빌드·실행해도 됩니다. 

#include <stdio.h>

int main(void) {
    printf("Hello, C!\n");
    return 0;
}
부분 쉬운 뜻 정확히 알아둘 점
#include <stdio.h> 출력 도구 사용에 필요한 안내서 읽기 표준 입출력 헤더의 선언 등을 포함합니다. printf의 실제 구현은 라이브러리와 연결됩니다.
int main(void) 프로그램의 출발 함수 일반적인 콘솔 C 프로그램의 시작점입니다. void는 전달받는 인자가 없다는 뜻입니다.
{ … } 함수의 작업 범위 중괄호로 시작과 끝을 묶습니다.
printf("Hello, C!\n"); 문장을 화면에 표시 큰따옴표 안이 출력 형식입니다. \n은 줄바꿈입니다.
return 0; 정상 종료를 알림 운영체제에 종료 상태를 전달합니다. 화면에 0을 출력하지 않습니다.

함께 실습: 첫 실행을 확인하는 네 단계

  1. 위 코드를 직접 입력해 hello.c로 저장합니다.
  2. 컴파일 후 Hello, C!가 나오는지 확인합니다.
  3. 문장을 My first program으로 바꿔 저장합니다.
  4. 다시 컴파일한 뒤 실행합니다. 소스만 바꾸고 옛 실행 파일을 실행하면 이전 결과가 나옵니다.
증상 가능한 원인 바로 해볼 일
gcc를 찾을 수 없음 GCC 미설치 또는 PATH 미설정 강사가 준비한 C 환경으로 먼저 첫 실행. 본인 환경에서는 GCC 설치 위치·PATH 확인 후 터미널 다시 열기
hello.c: No such file 터미널이 다른 폴더에 있음 Get-Location과 Get-ChildItem으로 현재 경로·파일 확인
expected ; … 세미콜론 누락 등 문법 오류 오류가 가리키는 줄과 그 바로 윗줄 확인
컴파일 실패 후 예전 결과가 나옴 이전 실행 파일을 다시 실행 컴파일 오류를 먼저 해결하고 새 빌드가 성공했을 때 실행
한글이 깨짐 소스·터미널 인코딩 불일치 첫 실습은 영문 출력으로 진행하고, 편집기 저장 인코딩과 터미널 표시 환경을 맞추기
첫날 약속

출력 결과가 예상과 다르면 마지막 줄만 보지 말고 값이 마지막으로 바뀐 줄을 찾습니다. 오류 메시지는 실패 판정이 아니라 수정할 위치를 알려주는 단서입니다.

03 · 기초 — 변수는 이름표가 붙은 저장 공간

카페 주문 장부에 “잔 수 3”을 적는다고 생각해 봅시다. cups는 칸의 이름, int는 그 칸에 저장할 값의 종류, 3은 현재 내용입니다. 비유에서 출발하되, C에서 변수는 자료형을 가진 객체를 이름으로 가리키는 것으로 이해하면 됩니다. 

int cups = 3;
int price = 2400;
int total = cups * price;
printf("%d\n", total);

위처럼 #include와 main이 없는 짧은 코드는 앞 절의 main 중괄호 안, return 0; 앞에 넣습니다. 뒤에 나오는 짧은 예제와 문제에도 같은 규칙을 적용합니다.

실행한 줄 cups price total 화면
int cups = 3; 3 아직 선언 전 아직 선언 전 출력 없음
int price = 2400; 3 2400 아직 선언 전 출력 없음
int total = cups * price; 3 2400 7200 출력 없음
printf(...); 3 2400 7200 7200 후 줄바꿈

대입은 계산 결과를 덮어쓰는 작업

int stock = 12;
int saved = stock;
stock = stock - 4;
printf("%d %d\n", stock, saved);

stock = stock - 4;는 오른쪽의 기존 값 12로 12−4를 계산한 뒤, 왼쪽 칸을 8로 덮어씁니다. saved에는 앞서 12라는 값을 복사해 두었습니다. stock이 바뀌어도 saved가 저절로 바뀌지 않습니다. saved = stock;을 다시 실행해야 새 값이 복사됩니다.

자주 하는 오해

=는 대입이고 ==는 같은지 비교입니다. stock == 8;은 비교 결과를 만들 뿐 stock에 8을 저장하지 않습니다. 지역 변수는 선언만 하면 0으로 초기화되지 않습니다. int x; 다음에 값을 넣지 않고 읽는 코드는 오늘의 출력 예측 대상이 아닙니다. int x = 0;처럼 처음 값을 정하세요.

출력은 사진, 변수는 현재 상태

int n = 4;
printf("%d ", n);
n = 9;
printf("%d\n", n);

첫 출력 4는 이미 화면에 남았습니다. 뒤에서 n을 9로 바꿔도 첫 출력이 9로 수정되지는 않습니다. 추적표에는 변수 상태와 출력 누적 칸을 따로 둡니다.

04 · 기초에서 응용으로 — 자료형과 출력 형식

자료형은 “값을 어떤 종류로 저장하고 계산할 것인가”를 정합니다. 사람 수는 보통 정수, 평균 점수는 소수 부분이 필요한 실수, 좌석 등급 한 글자는 문자로 표현합니다. 아래 크기는 흔한 환경의 예이며 언어가 모든 환경에서 똑같은 바이트 수를 보장하는 것은 아닙니다.

자료형 사용 예 printf 형식 주의
int int people = 7; %d 정수. 흔히 4바이트이지만 고정 규칙은 아님
double double average = 82.5; %f 또는 %.1f 실수. %.1f는 소수점 아래 한 자리 표시
float float rate = 1.5f; %f 출력 호출 시 double로 승격됨. 오늘 실수 계산은 double 중심
char char grade = 'B'; %c 작은따옴표의 문자 하나. char의 크기는 C에서 1바이트
문자열 리터럴 "Welcome" %s 큰따옴표로 묶은 문자열. 배열·널 문자는 03일차에 학습 
int count = 6;
double weight = 2.75;
char grade = 'B';
printf("count=%d weight=%.2f grade=%c\n", count, weight, grade);

첫 번째 %d는 count, 두 번째 %.2f는 weight, 세 번째 %c는 grade에 대응합니다. 쉼표로 나열한 값의 순서와 형식을 맞춥니다. %.2f는 출력 모양을 정할 뿐 변수에 저장된 값을 고치지 않습니다. 형식이 맞지 않는 printf는 임의의 출력 답을 붙이지 말고 코드를 수정해야 합니다.

서식 기호 작은 사전

표현 화면에서의 의미 예
\n 다음 줄로 이동 printf("A\nB"); → A와 B가 다른 줄
공백 한 칸 그대로 한 칸 출력 printf("%d %d", 2, 5); → 2 5
%% 퍼센트 기호 하나 printf("80%%"); → 80%
%d / %f / %c / %s 정수 / 실수 / 문자 / 문자열 값의 자료형과 형식을 대응시킨다

응용 예제: 주문서 한 줄 만들기

int cups = 4;
int unit = 2300;
double coupon = 500.0;
double pay = cups * unit - coupon;
printf("cups=%d pay=%.2f\n", cups, pay);

4×2300은 정수 9200입니다. 여기에 double인 coupon을 빼면서 실수 계산을 합니다. 손으로 먼저 8700을 구한 후 출력 형식 때문에 8700.00이 되는 것을 확인하세요. 원 단위 정산 정책은 별도 요구사항으로 정해야 합니다. 여기서는 자료형 연습을 위해 실수를 사용합니다.

문자와 문자열

'B'와 "B"는 다릅니다. 전자는 문자 하나를 나타내는 정수 문자 상수이고, 후자는 문자열 리터럴입니다. char grade = 'B';와 printf("%c", grade);를 한 쌍으로 익히세요.

05 · 응용 — 연산자를 실제 계산으로 이해하기

① 산술 연산과 정수 나눗셈

연산자 의미 예와 결과
+ − * 더하기·빼기·곱하기 7 + 2 → 9 / 7 - 2 → 5 / 7 * 2 → 14
/ 나눗셈 7 / 2 → 3, 7.0 / 2 → 3.5
% 정수 나머지 7 % 2 → 1. 정수 피연산자에 사용

쿠키 17개를 5명에게 똑같이 나눠 주면 한 사람당 3개, 남는 쿠키는 2개입니다. 17 / 5가 몫 3, 17 % 5가 나머지 2입니다. 두 피연산자가 정수이면 /의 결과도 정수입니다. double 변수에 나중에 담아도 버려진 소수 부분은 복원되지 않습니다. 

int cookies = 17, people = 5;
double a = cookies / people;
double b = (double)cookies / people;
double c = (double)(cookies / people);
printf("%.1f %.1f %.1f\n", a, b, c);
  1. a: 정수끼리 17/5를 먼저 계산해 3. 이를 double에 저장하여 3.0.
  2. b: cookies의 값을 double로 변환한 뒤 17.0/5.0을 계산해 3.4.
  3. c: 괄호 속 정수 나눗셈을 먼저 끝내 3. 그 뒤 double로 변환하므로 3.0.
형 변환의 위치

(double)cookies는 이 식에서 사용할 값을 변환합니다. cookies 변수 자체의 선언을 double로 바꾸지 않습니다. 정확한 평균을 구하려면 (double)sum / count처럼 나누기 전에 변환합니다.

② 비교·논리 연산: 질문의 답은 0 또는 1

종류 뜻 예
> >= < <= 크다·이상·작다·이하 age >= 18
== != 같다·다르다 stock == 0, stock != 0
&& 그리고: 둘 다 참 age >= 18 && ticket == 1
|| 또는: 하나 이상 참 member == 1 || coupon == 1
! 참·거짓 뒤집기 !0 → 1, !7 → 0

C에서 조건으로 쓰이는 0은 거짓, 0이 아닌 값은 참으로 취급합니다. 비교·논리 연산의 결과는 int 값 0 또는 1입니다. 예를 들어 2 && 8의 결과는 8이 아니라 1입니다. &와 |는 다른 비트 연산자이며 오늘은 사용하지 않습니다. 

int age = 18, ticket = 0;
printf("%d %d %d\n", age >= 18, age >= 18 && ticket == 1, !(ticket == 1));

age≥18은 참이지만 표가 없으므로 입장 조건 전체는 거짓입니다. 표가 있다는 명제(ticket==1)는 거짓이므로 이를 뒤집은 결과는 참입니다. 18 <= age <= 65처럼 수학식으로 연결하지 말고 age >= 18 && age <= 65로 작성합니다.

③ 연산 우선순위: 계산 순서와 평가 순서를 구별하기

높은 쪽부터 대표 연산자 예
묶기 ( ) (2 + 3) * 4 → 20
단항 ! / (double) / 전위 ++ -- !0 → 1
곱셈 계열 * / % 2 + 3 * 4 → 14
덧셈 계열 + - 9 - 4 + 2 → 7
대소 비교 < <= > >= 3 + 2 > 4 → 1
같음 비교 == != 5 > 4 == 1 → 1
논리 AND 다음 OR && 다음 || 1 || 0 && 0 → 1
대입 = += -= 등 x = 2 + 3 → x에 5 저장

이 표는 오늘 사용하는 연산자만 추린 것입니다. 우선순위는 식이 어떻게 묶이는지를 정하며, 모든 하위 식이 왼쪽부터 실행된다는 뜻은 아닙니다. 특히 함수 인자 사이의 평가 순서를 임의로 가정하지 않습니다. 헷갈리는 논리식은 괄호를 넣어 의도를 드러내세요.

④ 복합 대입: 현재 값을 갱신하는 약속

int points = 10;
points += 7;
points *= 2;
points -= 4;
printf("%d\n", points);

오늘의 단순 변수에서 points += 7;은 points = points + 7;과 같은 갱신입니다. 10→17→34→30을 한 줄씩 적습니다.

06 · 심화 — 증감, 단락 평가, 잘못된 예측 피하기

전위·후위 증감은 “식의 값”과 “저장된 값”을 나누어 보기

++는 1 증가, --는 1 감소입니다. 전위 ++n은 갱신한 값을 식의 값으로 사용하고, 후위 n++는 갱신 전 값을 식의 값으로 사용합니다. 후위를 “프로그램 맨 마지막에 증가”라고 외우면 틀립니다. 아래처럼 문장이 끝나면 증가 결과가 다음 문장에 반영됩니다. 

int n = 6;
int a = n++;
int b = ++n;
printf("%d %d %d\n", n, a, b);
문장 식에서 전달한 값 문장 완료 후 n a b
int n = 6; 6 6 — —
int a = n++; 기존 n인 6 7 6 —
int b = ++n; 증가한 n인 8 8 6 8

단독 문장인 n++;와 ++n;는 둘 다 다음 문장에 도달했을 때 n이 1 증가해 있습니다. 차이는 식의 값을 다른 곳에서 사용할 때 드러납니다.

단락 평가: 뒤쪽 질문을 하지 않는 경우

A && B는 A가 거짓이면 B를 평가하지 않습니다. A || B는 A가 참이면 B를 평가하지 않습니다. 앞쪽 결과만으로 전체 답이 결정되기 때문입니다. “회원이거나 초대권이 있는가?”에서 이미 회원이라면 초대권을 확인하지 않아도 참인 것과 같습니다. 

int x = 0;
int a = (0 && ++x);
int b = (1 || ++x);
int c = (1 && ++x);
printf("%d %d %d %d\n", x, a, b, c);

a에서는 앞이 0이므로 ++x를 건너뜁니다. b에서는 앞이 1이므로 또 건너뜁니다. c에서만 ++x가 실행되어 x=1입니다. a·b·c에는 각각 0·1·1이 저장됩니다. 읽기 쉬운 실무 코드는 부수 효과를 조건식에 과하게 섞지 않습니다. 시험 추적에서는 오른쪽 식이 실제로 평가됐는지를 기록하세요.

0으로 나누기와 음수 나눗셈

int d = 0;
int safe = (d != 0 && 12 / d > 2);
printf("%d\n", safe);

d!=0이 거짓이라 12/d를 계산하지 않으므로 이 예는 안전합니다. 조건 순서를 바꿔 12 / d > 2 && d != 0로 쓰면 앞에서 이미 0으로 나누게 됩니다. 정수의 0 나눗셈은 정해진 출력이 없습니다. C11 정수 나눗셈은 0 쪽으로 소수 부분을 버립니다. -17 / 5는 -3, -17 % 5는 -2이며, a == (a/b)*b + a%b 관계로 확인할 수 있습니다. 오늘의 금액 예제에는 음수를 쓰지 않습니다.

출력값을 정할 수 없는 코드를 숫자 문제로 만들지 않기

i++ + ++i 또는 printf("%d %d", i++, i++);처럼 같은 변수를 순서가 정해지지 않은 채 여러 번 변경하는 식은 C에서 미정의 동작을 일으킵니다. “왼쪽부터 하면 이 숫자”라는 답을 붙이지 않습니다. 변경을 각 문장으로 분리하세요. 초기화하지 않은 지역 변수 읽기, 맞지 않는 printf 형식, 범위 초과 계산도 피합니다. 이 교재의 실행형 문제는 이런 출력 불확정 코드를 사용하지 않습니다.

심화 종합 예제: 관람권 묶음 계산

int visitors = 23;
int bundle = 4;
int groups = visitors / bundle;
int remain = visitors % bundle;
double average = (double)visitors / bundle;
int exact = (remain == 0);
printf("%d %d %.2f %d\n", groups, remain, average, exact);

완성 묶음은 5개, 남는 사람은 3명입니다. average는 23/4의 실수 계산값이며 필요한 묶음 수를 올림한 값이 아닙니다. “모두를 넣을 수 있는 최소 묶음 수”가 요구되면 계산 목적이 달라집니다. 다음 연습에서 양의 정수에 한정한 올림 공식을 직접 다룹니다.

07 · 실습 도구 — 손 추적과 조건 변경

코드를 실행해서 답만 확인하면 이유를 놓치기 쉽습니다. 먼저 오른쪽 식을 계산하고, 왼쪽 변수에 저장한 뒤, 출력이 있는 줄에서만 화면 칸을 채우세요. 

int a = 9, b = 4;
int c = a / b;
a += b;
b = a % 5;
printf("%d %d %d\n", a, b, c);
완료한 줄 a b c 출력 누적
선언·초기화 9 4 — 없음
c = a / b 9 4 2 없음
a += b 13 4 2 없음
b = a % 5 13 3 2 없음
printf 13 3 2 13 3 2 후 줄바꿈

조건 변경: a의 초기값만 10으로 바꾸면 c=2, a=14, b=4라서 14 4 2입니다. 한 번에 하나만 바꾸면 어떤 규칙 때문에 결과가 바뀌었는지 설명하기 쉽습니다.

  1. 예상: 출력 문자열을 공백·줄바꿈까지 종이에 쓴다.
  2. 추적: 값을 덮어쓰는 줄마다 표를 갱신한다.
  3. 실행: 컴파일 성공 후 결과와 비교한다.
  4. 설명: 최초로 예상과 달라진 줄을 찾는다.
  5. 변형: 초기값·연산자·형 변환 위치 중 하나만 바꿔 재추적한다.
디버깅용 출력

중간값을 확인하려면 printf("a=%d b=%d\n", a, b);를 문장 사이에 넣습니다. 최종 답안을 작성할 때는 원래 코드에 있던 출력만 답합니다. 추가한 디버깅 출력을 원래 정답에 섞지 마세요.

a = a % b + 6;
b = (a >= 8 && c > 3.0) + 2;
printf("%d %d %.2f\n", a, b, c);
정답·해설 보기
정답 / 예시 답안 
8 3 3.50

풀이: c는 (double)14/4=3.5입니다. a를 14%4+6=8로 바꿉니다. b는 (a>=8)&&(c>3.0)=1에 2를 더해 3입니다. c는 바뀌지 않습니다.

조건 변경: a의 초기값만 15로 바꾸면 9 3 3.75입니다.

09 · 당일 범위 점검 5문항

M01~M05를 8분 동안 실행·검색·해설 없이 풉니다. 남은 7분에 채점하고 틀린 코드를 실행·추적하여 원인을 기록합니다. 주간 모의고사는 05일차에 진행합니다.

10점 채점 기준

총 10점, 각 2점. M01~M04는 출력 전체가 맞으면 2점, 일부만 맞고 추적 근거가 맞으면 1점. M05는 정확한 형 변환 답 2점, 의미는 맞지만 표현이 불완전하면 1점. 단순 공백·줄바꿈 표기 누락은 일관된 기준으로 최대 1점 감점합니다. 8점 이상을 권장하며 공식 시험 기준과는 별개입니다.

기초

M01 · 값 복사와 갱신

출력값을 쓰세요.

int a = 12;
int b = a;
a /= 2;
printf("%d %d\n", a, b);
정답·해설 보기
정답 / 예시 답안 
6 12

풀이: b에 12를 복사한 다음 a만 6으로 바뀝니다.

채점: 문항당 2점. 아래 채점 기준을 참고하세요.

기초

M02 · 몫·나머지·실수

출력값을 쓰세요.

int n = 17, d = 5;
printf("%d %d %.1f\n", n / d, n % d, (double)n / d);
정답·해설 보기
정답 / 예시 답안 
3 2 3.4

풀이: 17/5=3, 17%5=2, 17.0/5=3.4입니다.

채점: 문항당 2점. 아래 채점 기준을 참고하세요.

기초

M03 · 후위 감소와 전위 증가

출력값을 쓰세요.

int n = 9;
int a = n--;
int b = ++n;
printf("%d %d %d\n", n, a, b);
정답·해설 보기
정답 / 예시 답안 
9 9 9

풀이: a=n--에서 a=9, n=8. b=++n에서 n=9, b=9입니다.

채점: 문항당 2점. 아래 채점 기준을 참고하세요.

응용

M04 · 논리와 단락

출력값을 쓰세요.

int x = 0;
int a = (0 && ++x);
int b = (0 || ++x);
printf("%d %d %d\n", x, a, b);
정답·해설 보기
정답 / 예시 답안 
1 0 1

풀이: a의 오른쪽은 건너뜁니다. b의 왼쪽 0은 거짓이므로 오른쪽 ++x를 평가해 x=1, b=1입니다.

채점: 문항당 2점. 아래 채점 기준을 참고하세요.

응용

int sum = 25, count = 4;

10 · 핵심 정리·오답노트·다음 수업

오늘 남길 핵심 용어 다섯 개

용어 내 말로 설명하는 예
변수이름으로 가리키는 저장 공간. 대입하면 현재 값이 갱신된다.
자료형값의 종류와 표현·연산 규칙을 정한다.
형 변환계산에 사용하는 값의 자료형을 바꾼다. 변환 위치가 중요하다.
증감 연산전위·후위에서 식의 값과 갱신 후 변수 값을 구별한다.
단락 평가&&와 ||에서 왼쪽 결과로 전체가 결정되면 오른쪽을 평가하지 않는다.

오답노트 한 장

  • □ 소스를 바꾼 뒤 다시 컴파일해야 함을 설명한다.
  • □ =와 ==를 구별하고 변수·화면을 따로 추적한다.
  • □ 17/5, 17%5, (double)17/5의 차이를 말한다.
  • □ n++와 ++n의 식 값과 갱신 후 값을 나누어 적는다.

02일차에는 비교·논리식으로 if·else·switch의 실행 흐름을 고르고, 반복문으로 같은 계산을 여러 번 수행합니다. 틀린 문제 하나의 초기값을 바꿔 다음 수업 시작 때 다시 풀어 보세요.
