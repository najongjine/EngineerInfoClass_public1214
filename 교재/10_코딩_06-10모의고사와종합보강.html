쉬운 설명 · 기본형은 복사본, 반환값은 받아야 사용

작업대에 숫자 쪽지를 복사해 건네는 상황을 떠올리세요. 작업대 안 쪽지를 고쳐도 원래 쪽지는 그대로입니다. C 함수와 Java 메서드는 모두 값 전달입니다. return은 호출한 자리에 결과를 보내며 printf·println과 다릅니다.

언어 · C11

#include <stdio.h>
int add(int n) { n+=5; return n; }
int main(void) {
    int a=9;
    int b=add(a);
    printf("%d %d\n",a,b);
    return 0;
}

실행 결과

9 14

언어 · Java

public class Main {
    static int add(int n) { n+=5; return n; }
    public static void main(String[] args) {
        int a=9;
        int b=add(a);
        System.out.println(a+" "+b);
    }
}

실행 결과

9 14

두 언어 모두 a는 9, 반환값을 받은 b는 14입니다. a를 바꾸려면 a=add(a)로 받아야 합니다. Java 메서드는 Main 클래스 안이면서 main 바깥에 정의합니다. 오늘의 Java 호출은 객체 없이 부르는 static 메서드입니다.

응용 설명 · 주소·참조를 복사해 같은 원본 접근

집 주소를 두 장 복사하면 종이는 두 장이어도 가리키는 집은 같습니다. C 포인터의 주소 값, Java 배열 참조 값이 복사되면 같은 원소를 수정할 수 있습니다. 매개변수 자체를 다른 대상으로 재대입하는 것은 원본 변수의 재대입이 아닙니다.

언어 · C11

#include <stdio.h>
void touch(int *p) { *p+=4; }
int main(void) {
    int a=9;
    touch(&a);
    printf("%d\n",a);
    return 0;
}

실행 결과

13

언어 · Java

public class Main {
    static void touch(int[] a) { a[0]+=4; a=new int[]{90}; }
    public static void main(String[] args) {
        int[] a={9};
        touch(a);
        System.out.println(a[0]);
    }
}

실행 결과

13
호출자 a ─┐
         ├──→ 원래 배열 [9] → 원소 변경 후 [13]
매개변수 ─┘
매개변수 = 새 배열 → 매개변수만 새 연결, 호출자 연결 유지

심화 설명 · 호출마다 지역 칸, static 수명·오버로딩 구분

C의 함수 내부 static 지역변수는 호출 사이 값을 유지합니다. Java의 static 메서드라는 말은 그 안 모든 지역변수가 값을 유지한다는 뜻이 아닙니다. 재귀는 호출마다 다른 매개변수 칸을 그린 뒤 마지막 호출부터 반환값을 계산합니다. Java 오버로딩은 입력의 개수·타입·타입 순서로 구별하며 반환형만으로 나누지 않습니다.

언어 · C11

#include <stdio.h>
int r(int n) { if(n==0) return 2; return r(n-1)+3; }
int main(void) {
    printf("%d\n",r(2));
